## Intuition: Sensitivity to Tiny Nudges

A derivative $\frac{df}{dx}$ answers a practical question: *if I nudge $x$ by a tiny amount $\epsilon$, how much does output $f(x)$ respond?* When a model has millions of weights $\theta_1, \dots, \theta_p$, the **<GlossaryTerm term="Gradient">gradient</GlossaryTerm>** packs every weight's sensitivity into a single vector $\nabla_\theta L$.

<Callout type="math-deep-dive" title="Multivariate Chain Rule & Finite-Difference Gradient Check">
  For a composite function $L(g(h(w)))$, the chain rule multiplies local derivatives:

  <Math tex="\frac{\partial L}{\partial w} = \frac{\partial L}{\partial g} \cdot \frac{\partial g}{\partial h} \cdot \frac{\partial h}{\partial w}" display />

  To catch bugs in custom backward passes, compare analytic gradients against central finite differences:

  <Math tex="\frac{\partial L}{\partial w} \approx \frac{L(w + \epsilon) - L(w - \epsilon)}{2\epsilon}, \quad \epsilon = 10^{-5}" display />
</Callout>

<Callout type="tip" title="Why Central Differences Beat Forward Differences">
  Central differences cancel the second-order Taylor error term $O(\epsilon)$, yielding $O(\epsilon^2)$ precision—an essential sanity check whenever implementing custom autograd ops.
</Callout>

def forward_loss(x, w, b, y):
    z = w * x + b
    a = 1.0 / (1.0 + np.exp(-z))  # sigmoid
    loss = 0.5 * (a - y) ** 2
    return loss, a

x, w, b, y = 1.5, 0.8, -0.2, 1.0
loss, a = forward_loss(x, w, b, y)

# Analytic chain rule
dL_da = a - y
da_dz = a * (1.0 - a)
dL_dw = dL_da * da_dz * x

# Central finite-difference verification
eps = 1e-5
loss_plus, _ = forward_loss(x, w + eps, b, y)
loss_minus, _ = forward_loss(x, w - eps, b, y)
numeric_dL_dw = (loss_plus - loss_minus) / (2.0 * eps)

print(f"Analytic  dL/dw: {dL_dw:.8f}")
print(f"Numerical dL/dw: {numeric_dL_dw:.8f}")`}
