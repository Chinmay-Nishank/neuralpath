## Intuition: Guessing Rules vs. Learning Rules

In traditional software engineering, you write explicit rules by hand: `if price > 500: discount = 0.10`. That works well when the rule is simple and fixed.

In machine learning, we flip the direction. We provide **examples** $(x, y)$—inputs paired with observed outcomes—and ask an algorithm to discover the rule automatically. A <GlossaryTerm term="Model">model</GlossaryTerm> is simply a flexible mathematical recipe $f(x; \theta)$ with tunable knobs $\theta$ (parameters).

<Callout type="note" title="Parameters vs. Hyperparameters">
  **Parameters** ($\theta$, like weights $w$ and bias $b$) are learned automatically from data during training. **Hyperparameters** (like learning rate or tree depth) are choices *you* configure before training starts.
</Callout>

## The Three Ingredients of Supervised Learning

1. **Data $(X, y)$:** Input features $X$ (e.g., apartment area, bedrooms) and ground-truth targets $y$ (price).
2. **A <GlossaryTerm term="Loss Function">Loss Function</GlossaryTerm> $L(\theta)$:** A single number scoring how wrong our current guesses $\hat{y} = f(x; \theta)$ are.
3. **An Optimizer:** A procedure that adjusts $\theta$ to shrink $L(\theta)$ without memorizing accidental noise.

<Callout type="math-deep-dive" title="Mathematical Formulation of Empirical Risk Minimization">
  Given a dataset of $N$ examples $\{(x_i, y_i)\}_{i=1}^N$, training searches for parameters $\theta^*$ that minimize average error:

  <Math tex="\theta^* = \arg\min_\theta \frac{1}{N} \sum_{i=1}^{N} \ell\big(f(x_i; \theta),\, y_i\big)" display />

  For continuous targets, squared error $\ell(\hat{y}, y) = (\hat{y} - y)^2$ penalizes large misses heavily.
</Callout>

# Input feature: house size in 1000 sq ft; target: price in $100k
area = np.array([0.85, 1.10, 1.40, 1.80, 2.20, 2.60])
price = np.array([2.15, 2.68, 3.52, 4.25, 4.95, 6.42])

# Model: y_hat = w * x + b
w, b = 0.0, 0.0
lr = 0.08

for epoch in range(250):
    pred = w * area + b
    error = pred - price
    loss = np.mean(error ** 2)
    # Gradients of mean squared error
    dw = (2.0 / len(area)) * np.dot(error, area)
    db = (2.0 / len(area)) * np.sum(error)
    w -= lr * dw
    b -= lr * db

print(f"Learned parameters: w={w:.3f}, b={b:.3f}, MSE={loss:.4f}")
print(f"Predicted price for 2,000 sq ft: \${(w * 2.0 + b) * 100:.1f}k")`}
