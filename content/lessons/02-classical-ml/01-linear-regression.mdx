## Intuition: Fitting a Hyperplane Through Noisy Observations

Suppose you predict home prices from square footage, bedrooms, and age. Linear regression posits that the target is a weighted sum of inputs plus an intercept:

<Math tex="\hat{y} = X w + b" display />

Geometrically, Ordinary Least Squares (OLS) chooses weights $w$ so the residual vector $y - \hat{y}$ is **perpendicular** to every input feature column—minimizing squared vertical distances.

## Interactive Check: Underfitting vs. Curve Complexity

Set polynomial degree to **1** below to see a straight linear fit, then observe how adding degree terms bends the model.

<Callout type="math-deep-dive" title="Closed-Form Normal Equation">
  Augmenting $X$ with a column of ones gives $\hat{y} = \tilde{X}\theta$. Setting the gradient of $\|y - \tilde{X}\theta\|_2^2$ to zero yields:

  <Math tex="\theta^* = (\tilde{X}^T \tilde{X})^{-1} \tilde{X}^T y" display />

  Inverting $\tilde{X}^T \tilde{X}$ costs $O(d^3)$ time. When feature count $d$ exceeds ~10,000, iterative gradient solvers beat matrix inversion.
</Callout>
