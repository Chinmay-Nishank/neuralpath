## Intuition: Squashing Logits into Valid Probabilities

Linear regression predicts unbounded numbers $(-\infty, +\infty)$, which breaks when predicting probabilities $P(y = 1 \mid x) \in [0, 1]$. **Logistic regression** passes a linear score $z = w^T x + b$ (the *log-odds*) through the **sigmoid** curve:

<Math tex="\hat{p} = \sigma(z) = \frac{1}{1 + e^{-z}}" display />

Notice that logistic regression still draws a **straight hyperplane boundary** where $w^T x + b = 0$ ($\hat{p} = 0.5$).

<Callout type="math-deep-dive" title="Binary Cross-Entropy Loss & Gradient">
  Minimizing negative log-likelihood gives Binary Cross-Entropy (Log Loss):

  <Math tex="L(w, b) = -\frac{1}{N} \sum_{i=1}^N \Big[ y_i \log \hat{p}_i + (1 - y_i) \log(1 - \hat{p}_i) \Big]" display />

  Remarkably, combining sigmoid with log loss simplifies the gradient to:
  <Math tex="\nabla_w L = \frac{1}{N} X^T (\hat{p} - y)" display />
</Callout>

rng = np.random.default_rng(1)
X0 = rng.normal(loc=[-1.2, -1.0], scale=0.7, size=(40, 2))
X1 = rng.normal(loc=[1.2, 1.0], scale=0.7, size=(40, 2))
X = np.vstack([X0, X1])
y = np.array([0] * 40 + [1] * 40, dtype=float)

w = np.zeros(2)
b = 0.0
for _ in range(300):
    z = X @ w + b
    p = 1.0 / (1.0 + np.exp(-np.clip(z, -20, 20)))
    err = p - y
    w -= 0.2 * (X.T @ err) / len(y)
    b -= 0.2 * np.mean(err)

acc = np.mean((1.0 / (1.0 + np.exp(-(X @ w + b))) >= 0.5) == y)
print(f"Weights: {w.round(3)}, Bias: {b:.3f}, Accuracy: {acc:.2%}")`}

def binary_cross_entropy(y_true, y_prob):
    y_true = np.asarray(y_true, dtype=float)
    p = np.clip(np.asarray(y_prob, dtype=float), 1e-12, 1.0 - 1e-12)
