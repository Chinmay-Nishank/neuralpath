## Intuition: Wisdom of Independent vs. Sequential Crowds

Single decision trees are brittle. Two distinct ensemble philosophies fix this:

1. **Random Forests (Bagging):** Train hundreds of deep trees in parallel on bootstrap samples, sampling only $\sqrt{d}$ candidate features at each split so strong features don't make every tree identical. Averaging their votes slashes **variance**.
2. **Gradient Boosting (XGBoost / LightGBM / HistGradientBoosting):** Train shallow trees **sequentially**, where each new tree fits the *negative gradient (residuals)* left behind by the previous ensemble—progressively reducing **bias**.

<Viz type="bias-variance" />

<Callout type="tip" title="Tabular ML Baseline Rule">
  On structured tabular datasets (under ~1M rows), `HistGradientBoostingClassifier` / LightGBM / XGBoost almost always outperform deep MLPs out-of-the-box with far less hyperparameter tuning.
</Callout>

<Callout type="math-deep-dive" title="Stage-Wise Additive Boosting">
  At stage $m$, gradient boosting computes pseudo-residuals $r_{im} = -\frac{\partial L(y_i, F_{m-1}(x_i))}{\partial F_{m-1}(x_i)}$, fits a shallow tree $h_m(x)$ to $r_{im}$, and shrinks its contribution by learning rate $\nu \in (0, 1]$:

  <Math tex="F_m(x) = F_{m-1}(x) + \nu \, h_m(x)" display />
</Callout>

from sklearn.tree import DecisionTreeRegressor

rng = np.random.default_rng(7)
X = np.linspace(-2, 2, 60).reshape(-1, 1)
y = np.sin(2.0 * X[:, 0]) + rng.normal(0, 0.12, size=60)

# Toy Gradient Boosting for MSE loss (residuals = y - F)
F = np.full_like(y, np.mean(y))
lr = 0.2
for step in range(15):
    residuals = y - F
    tree = DecisionTreeRegressor(max_depth=2, random_state=step).fit(X, residuals)
    F += lr * tree.predict(X)
    if step in (0, 4, 14):
        mse = np.mean((y - F) ** 2)
        print(f"Boosting stage {step + 1:2d} | MSE: {mse:.4f}")`}
