## Intuition: Playing 20 Questions with Your Features

A decision tree asks a sequence of crisp threshold questions (`petal_length <= 2.45?`) to split mixed examples into pure leaf buckets. Unlike linear models or SVMs, decision trees are **invariant to monotonic feature scaling** (multiplying dollars by 100 doesn't change split order) and naturally capture non-linear feature thresholds.

<Callout type="math-deep-dive" title="Gini Impurity & Information Gain">
  For a node with class proportions $p_1, \dots, p_C$:

  <Math tex="G(t) = 1 - \sum_{c=1}^{C} p_c^2" display />

  A completely pure node ($p_k = 1$) has $G = 0$. Each split chooses feature $j$ and threshold $\tau$ maximizing weighted impurity reduction:

  <Math tex="\Delta G = G_{\text{parent}} - \left(\frac{N_L}{N} G_L + \frac{N_R}{N} G_R\right)" display />
</Callout>

def gini(y):
    if len(y) == 0:
        return 0.0
    _, counts = np.unique(y, return_counts=True)
    probs = counts / len(y)
    return float(1.0 - np.sum(probs ** 2))

x = np.array([1.2, 1.8, 2.3, 4.1, 4.8, 5.2])
y = np.array([0, 0, 0, 1, 1, 1])

parent_g = gini(y)
best_gain, best_t = -1.0, None
for t in np.unique(x)[:-1]:
    left = y[x <= t]
    right = y[x > t]
    gain = parent_g - (len(left)/len(y))*gini(left) - (len(right)/len(y))*gini(right)
    if gain > best_gain:
        best_gain, best_t = gain, float(t)

print(f"Best split threshold <= {best_t}, Gini gain = {best_gain:.4f}")`}
