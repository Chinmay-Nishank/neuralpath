## Intuition: Better Features Often Beat Bigger Models

In tabular machine learning, informative domain ratios (like `debt / income` or `price / area`) often boost accuracy more than switching algorithms. Equally critical: **<GlossaryTerm term="Data Leakage">data leakage</GlossaryTerm>** silently invalidates offline validation whenever preprocessing inspects test rows before splitting.

<Callout type="warning" title="Golden Rule of Leak-Free Pipelines">
  Wrap every scaler, imputer, encoder, and selector inside `sklearn.pipeline.Pipeline` BEFORE calling `cross_val_score` or `fit`. That guarantees statistics are computed strictly per training fold.
</Callout>

<Callout type="math-deep-dive" title="Standardization vs. Min-Max vs. Robust Scaling">
  - **StandardScaler:** $z = (x - \mu) / \sigma$ (zero mean, unit variance; ideal for linear models, SVMs, neural nets).
  - **RobustScaler:** uses median and IQR $(Q_{75} - Q_{25})$ when heavy outliers exist.
  - **One-Hot Encoding:** maps $K$ categories into orthogonal binary indicators (`handle_unknown="ignore"` protects inference from unseen categories).
</Callout>

from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.linear_model import Ridge
from sklearn.model_selection import cross_val_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler

df = pd.read_csv("/datasets/housing_mini.csv")
df["size_bucket"] = pd.cut(df["area_sqft"], bins=[0, 1400, 2200, 5000], labels=["sm", "md", "lg"]).astype(str)

num_cols = ["area_sqft", "bedrooms", "age_years", "distance_km"]
cat_cols = ["size_bucket"]

pre = ColumnTransformer([
    ("num", Pipeline([("imp", SimpleImputer(strategy="median")), ("sc", StandardScaler())]), num_cols),
    ("cat", OneHotEncoder(handle_unknown="ignore"), cat_cols),
])

pipe = Pipeline([("pre", pre), ("model", Ridge(alpha=1.0))])
r2 = cross_val_score(pipe, df[num_cols + cat_cols], df["price_k"], cv=4, scoring="r2")
print("Leak-free 4-fold CV R^2:", round(float(r2.mean()), 3))`}

def fit_transform_minmax(X_train, X_test):
    X_train = np.asarray(X_train, dtype=float)
    X_test = np.asarray(X_test, dtype=float)
    mn = X_train.min(axis=0)
    span = np.maximum(X_train.max(axis=0) - mn, 1e-12)
    return (X_train - mn) / span, (X_test - mn) / span`}
