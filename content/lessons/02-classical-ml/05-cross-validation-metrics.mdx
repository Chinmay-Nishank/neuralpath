## Intuition: Why 99% Accuracy Can Be Completely Useless

Suppose only 1% of transactions are fraudulent. A dummy classifier that predicts `"not fraud"` every single time achieves **99% accuracy** while catching **zero** fraud cases.

Instead of looking only at raw accuracy, dissect predictions with a **confusion matrix**, adjust your decision threshold, and measure Precision, Recall, <GlossaryTerm term="ROC-AUC">ROC-AUC</GlossaryTerm>, and PR-AUC.

<Callout type="tip" title="Stratified k-Fold Is Mandatory for Imbalanced Targets">
  Standard random splits can accidentally leave a fold with zero positive examples when classes are rare. `StratifiedKFold` preserves exact class ratios in every fold.
</Callout>

<Callout type="math-deep-dive" title="ROC-AUC vs. PR-AUC">
  - **ROC-AUC** plots True Positive Rate vs. False Positive Rate across all thresholds. Because FPR divides by all Negatives ($FP + TN$), massive negative classes can make ROC curves look artificially optimistic.
  - **PR-AUC** plots Precision vs. Recall, ignoring True Negatives completely—making it the gold standard for rare-event detection.
</Callout>

y_true = np.array([1, 1, 0, 0, 1, 0, 1, 0, 0, 0])
y_prob = np.array([0.88, 0.42, 0.65, 0.12, 0.91, 0.25, 0.55, 0.08, 0.30, 0.19])

for thresh in [0.35, 0.50, 0.70]:
    y_pred = (y_prob >= thresh).astype(int)
    tp = int(np.sum((y_true == 1) & (y_pred == 1)))
    fp = int(np.sum((y_true == 0) & (y_pred == 1)))
    fn = int(np.sum((y_true == 1) & (y_pred == 0)))
    prec = tp / max(1, tp + fp)
    rec = tp / max(1, tp + fn)
    f1 = (2 * prec * rec) / max(1e-9, prec + rec)
    print(f"thresh={thresh:.2f} | Precision={prec:.2f} Recall={rec:.2f} F1={f1:.2f}")`}

  exerciseSolution={`import numpy as np

def compute_f1(y_true, y_pred):
    yt = np.asarray(y_true) == 1
    yp = np.asarray(y_pred) == 1
    tp = int(np.sum(yt & yp))
    if tp == 0:
        return 0.0
    fp = int(np.sum((~yt) & yp))
    fn = int(np.sum(yt & (~yp)))
    prec = tp / (tp + fp)
    rec = tp / (tp + fn)
    return 2.0 * prec * rec / (prec + rec)`}
