## Intuition: Neighborhood Votes vs. Widest Street Margins

**k-Nearest Neighbors (k-NN)** memorizes training points and classifies a new query by majority vote among its $k$ closest neighbors. Small $k = 1$ creates jagged, high-variance islands; large $k$ smooths boundaries.

**Support Vector Machines (SVMs)** instead learn the separating hyperplane with the **widest margin** between classes, anchored solely by boundary-edge **support vectors**. With an **RBF kernel**, SVMs measure similarity in infinite-dimensional space without explicitly constructing high-dimensional coordinates.

<Callout type="math-deep-dive" title="The RBF (Gaussian) Kernel Function">
  The Radial Basis Function kernel measures localized proximity between two samples:

  <Math tex="K(x, x') = \exp\!\left(-\gamma \|x - x'\|_2^2\right)" display />

  Large $\gamma$ gives each support vector a narrow radius of influence (complex, high-variance islands); small $\gamma$ creates broad, smooth boundaries.
</Callout>

X_train = np.array([[0.0, 0.0], [0.2, 0.1], [2.0, 2.1], [2.2, 1.9], [0.1, 0.3]])
y_train = np.array([0, 0, 1, 1, 0])

def knn_predict(X_tr, y_tr, X_q, k=3):
    preds = []
    for q in X_q:
        dists = np.linalg.norm(X_tr - q, axis=1)
        nn_idx = np.argsort(dists)[:k]
        votes = y_tr[nn_idx]
        preds.append(int(np.round(np.mean(votes))))
    return np.array(preds)

queries = np.array([[0.15, 0.2], [2.1, 2.0]])
print("k-NN predictions (k=3):", knn_predict(X_train, y_train, queries, k=3))`}
