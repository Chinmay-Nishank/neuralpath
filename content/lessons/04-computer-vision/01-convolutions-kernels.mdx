## Intuition: Local Weight Sharing Beats Dense Connections

Flattening a modest $256 \times 256$ RGB image into an MLP input vector gives $196{,}608$ numbers—requiring tens of millions of weights in the *very first layer* and ignoring that nearby pixels form edges!

A <GlossaryTerm term="Convolution">2D convolution</GlossaryTerm> slides a tiny shared $3 \times 3$ kernel across the entire image, reusing the same $9$ weights at every coordinate. That delivers two superpowers: dramatic parameter efficiency and **translation equivariance** (shifting an object shifts its feature map proportionally).

<Callout type="math-deep-dive" title="Output Spatial Dimension Formula">
  For input size $H \times W$, square kernel $k$, padding $p$, and stride $s$:

  <Math tex="H_{\text{out}} = \left\lfloor \frac{H + 2p - k}{s} \right\rfloor + 1" display />

  With $k=3$, $p=1$, and $s=1$ ("same" padding), spatial resolution $H_{\text{out}} = H$ is preserved cleanly.
</Callout>

  code={`import numpy as np

def conv2d_valid(img, kernel, stride=1):
    H, W = img.shape
    kH, kW = kernel.shape
    out_h = (H - kH) // stride + 1
    out_w = (W - kW) // stride + 1
    out = np.zeros((out_h, out_w))
    for r in range(out_h):
        for c in range(out_w):
            patch = img[r*stride : r*stride + kH, c*stride : c*stride + kW]
            out[r, c] = np.sum(patch * kernel)
    return out

img = np.array([
    [0, 0, 10, 10, 10],
    [0, 0, 10, 10, 10],
    [0, 0, 10, 10, 10],
    [0, 0, 10, 10, 10],

], dtype=float)
sobel_x = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], dtype=float)
print("Vertical edge response:\n", conv2d_valid(img, sobel_x))`}
