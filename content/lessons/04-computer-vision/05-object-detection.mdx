## Intuition: Classification Meets Localization

Image classification answers *"what single label describes this frame?"* **Object detection** predicts a variable-length list of `(class, confidence, x_min, y_min, x_max, y_max)` boxes.

Two families dominate modern detection:
- **YOLO (Single-Stage Dense Detectors):** predict class scores and bounding offsets across multi-scale feature grids in real time, then filter overlapping duplicates with **Non-Maximum Suppression (NMS)**.
- **DETR (Detection Transformer):** replaces anchor priors and hand-crafted NMS entirely using learned object queries, Transformer cross-attention, and bipartite Hungarian set-matching loss!

<Callout type="math-deep-dive" title="Intersection over Union (IoU)">
  Given two boxes $A = (x_1, y_1, x_2, y_2)$ and $B = (x'_1, y'_1, x'_2, y'_2)$:

  <Math tex="\text{IoU}(A, B) = \frac{\text{Area}(A \cap B)}{\text{Area}(A) + \text{Area}(B) - \text{Area}(A \cap B)} \in [0, 1]" display />

  Detection benchmarks evaluate **mAP** (mean Average Precision) across IoU thresholds (such as `mAP@0.50:0.95`).
</Callout>

def box_iou(a, b):
    x1 = max(a[0], b[0])
    y1 = max(a[1], b[1])
    x2 = min(a[2], b[2])
    y2 = min(a[3], b[3])
    inter = max(0.0, x2 - x1) * max(0.0, y2 - y1)
    area_a = max(0.0, a[2] - a[0]) * max(0.0, a[3] - a[1])
    area_b = max(0.0, b[2] - b[0]) * max(0.0, b[3] - b[1])
    union = area_a + area_b - inter
    return inter / max(1e-9, union)

def nms(boxes, scores, iou_thresh=0.5):
    order = np.argsort(scores)[::-1]
    keep = []
    while len(order) > 0:
        idx = int(order[0])
        keep.append(idx)
        rest = []
        for j in order[1:]:
            if box_iou(boxes[idx], boxes[int(j)]) <= iou_thresh:
                rest.append(int(j))
        order = np.array(rest, dtype=int)
    return keep

boxes = np.array([[10, 10, 50, 50], [12, 12, 48, 48], [100, 100, 140, 140]], dtype=float)
scores = np.array([0.92, 0.81, 0.88])
print("Kept box indices after NMS:", nms(boxes, scores, iou_thresh=0.5))`}
