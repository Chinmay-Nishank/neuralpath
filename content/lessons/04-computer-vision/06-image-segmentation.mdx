## Intuition: Pixel-Precise Boundaries Need High-Resolution Skip Highways

Bounding boxes enclose background clutter on irregular objects like cells, roads, or tumors. **Segmentation** classifies every pixel `(H, W)`:
- **Semantic Segmentation:** tags every pixel with a category (`road`, `person`) without separating two adjacent people.
- **Instance Segmentation:** assigns separate masks per individual object.
- **Panoptic Segmentation:** unifies both background stuff and countable things.

Standard CNN encoders downsample images spatially to capture context, losing crisp borders. **U-Net** fixes this by concatenating high-resolution encoder feature maps directly into the decoder upsampling stages!

<Callout type="note" title="Promptable Foundation Segmentation: SAM">
  Meta's **Segment Anything Model (SAM / SAM 2)** pairs a ViT image encoder with a lightweight mask decoder conditioned on user prompts (points, boxes, or text/video tracking), enabling zero-shot object masks without task-specific retraining.
</Callout>

<Callout type="math-deep-dive" title="Dice Coefficient vs. Pixel Cross-Entropy">
  When foreground tumors occupy only 1% of an MRI slice, pixel-wise cross-entropy gives 99% accuracy for predicting all zeros! **Soft Dice Loss** directly optimizes mask overlap:

  <Math tex="\text{Dice}(P, G) = \frac{2 |P \cap G| + \epsilon}{|P| + |G| + \epsilon}, \qquad \mathcal{L}_{\text{Dice}} = 1 - \text{Dice}(P, G)" display />
</Callout>

import torch.nn as nn

class UNetUpBlock(nn.Module):
    def __init__(self, in_ch, skip_ch, out_ch):
        super().__init__()
        self.up = nn.ConvTranspose2d(in_ch, out_ch, kernel_size=2, stride=2)
        self.conv = nn.Sequential(
            nn.Conv2d(out_ch + skip_ch, out_ch, 3, padding=1),
            nn.ReLU(),
        )

    def forward(self, x, skip):
        x = self.up(x)
        x = torch.cat([x, skip], dim=1)  # Concatenate along channel axis
        return self.conv(x)
