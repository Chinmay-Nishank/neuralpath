## Intuition: Images as Sequences of Patches

A standard Transformer takes a sequence of vectors `(batch, num_tokens, d_model)`. **Vision Transformer (ViT)** turns an image into tokens in two clean steps:
1. Slice a $224 \times 224$ image into $16 \times 16$ non-overlapping tiles ($14 \times 14 = 196$ patches).
2. Linearly project each flattened $16 \times 16 \times 3 = 768$-value patch into `d_model` (which is algebraically identical to a `Conv2d(3, d_model, kernel_size=16, stride=16)`!), add positional embeddings, prepend a `[CLS]` token (or use global pooling), and run standard Transformer attention!

<Viz type="attention" />

<Callout type="note" title="Modern Vision Backbones: DINOv2 & SigLIP">
  Modern multimodal LLMs rarely rely on ImageNet-supervised ResNets. **SigLIP** trains ViT vision-language towers using pairwise sigmoid contrastive loss (removing CLIP's global batch softmax bottleneck), while **DINOv2** learns dense pixel-level semantic geometry purely via self-distillation with zero text labels.
</Callout>

<Callout type="math-deep-dive" title="Patch Token Count & Attention Scaling">
  For image size $H \times W$ and patch size $P$:
  <Math tex="N = \frac{H \cdot W}{P^2}" display />
  Self-attention scales quadratically $O(N^2)$ with patch count, so doubling image resolution quadruples $N$ and increases attention compute $16\times$ unless hierarchical windowing or token merging is applied.
</Callout>

  libraryCode={`import torch
import torch.nn as nn

class PatchEmbed(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_ch=3, d_model=384):
        super().__init__()
        self.proj = nn.Conv2d(in_ch, d_model, kernel_size=patch_size, stride=patch_size)
        num_patches = (img_size // patch_size) ** 2
        self.pos_emb = nn.Parameter(torch.zeros(1, num_patches, d_model))

    def forward(self, x):
        # (B, C, H, W) -> (B, d_model, H/P, W/P) -> (B, N, d_model)
        x = self.proj(x).flatten(2).transpose(1, 2)
        return x + self.pos_emb

pe = PatchEmbed()
out = pe(torch.randn(2, 3, 224, 224))
print("PyTorch ViT patch tokens:", tuple(out.shape))`}
