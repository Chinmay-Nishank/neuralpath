## Intuition: Never Train a ResNet from Scratch on 500 Photos

Early layers of ImageNet- or CLIP-pretrained models already detect universal oriented edges, corners, fur, metal, and textures. With **transfer learning**, you replace only the final classification head and adapt high-level features to your domain in minutes rather than days.

Pair transfer learning with **data augmentation** (random crops, horizontal flips, slight color jitter, MixUp) so your model cannot memorize exact pixel positions.

<Viz type="convolution" />

<Callout type="warning" title="Only Apply Label-Preserving Augmentations">
  Horizontal flipping preserves `"cat"` or `"car"`, but **vertical flipping** ruins street signs and horizontal flipping corrupts handwritten digits `"6"` vs `"9"` or left/right medical X-ray laterality!
</Callout>

<Callout type="math-deep-dive" title="MixUp Convex Data Augmentation">
  MixUp blends two training samples $(x_i, y_i)$ and $(x_j, y_j)$ with $\lambda \sim \text{Beta}(\alpha, \alpha)$:

  <Math tex="\tilde{x} = \lambda x_i + (1 - \lambda) x_j, \qquad \tilde{y} = \lambda y_i + (1 - \lambda) y_j" display />

  MixUp smooths decision boundaries between classes and strongly improves probability calibration.
</Callout>

def mixup_sample(x1, y1, x2, y2, lam=0.7):
    x_mix = lam * x1 + (1.0 - lam) * x2
    y_mix = lam * y1 + (1.0 - lam) * y2
    return x_mix, y_mix

img_a = np.ones((4, 4)) * 200.0
img_b = np.zeros((4, 4))
y_a = np.array([1.0, 0.0])  # Class 0
y_b = np.array([0.0, 1.0])  # Class 1

xm, ym = mixup_sample(img_a, y_a, img_b, y_b, lam=0.75)
print("Blended pixel value:", xm[0, 0], "Blended soft label:", ym)`}
