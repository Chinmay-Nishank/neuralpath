## Intuition: Reading Left and Right Simultaneously

When classifying sentiment, tagging named entities, or generating search embeddings, future tokens aren't forbidden—they're part of the input document!

**Encoder Transformers** (like BERT, RoBERTa, ModernBERT, and BGE/E5 embedding models) disable causal masking so every token attends to **all** surrounding tokens simultaneously. During pretraining, 15% of tokens are masked (`[MASK]`), and the model reconstructs the missing tokens from bidirectional context.

<Callout type="tip" title="Mean Pooling Beats [CLS] for Retrieval Embeddings">
  While original BERT classified sequences from a special `[CLS]` token, modern bi-encoder embedding models compute **attention-masked mean pooling** over all token embeddings followed by L2 normalization.
</Callout>

<Callout type="math-deep-dive" title="Masked Language Modeling Loss">
  Given masked token indices $\mathcal{M}$ inside sequence $\tilde{x}$:
  <Math tex="\mathcal{L}_{\text{MLM}} = -\frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \log P(x_i \mid \tilde{x})" display />
</Callout>

def masked_mean_pool(token_embs, attention_mask):
    # token_embs: (B, T, d), attention_mask: (B, T) with 1 for real tokens, 0 for padding
    mask = attention_mask[:, :, None].astype(float)
    summed = np.sum(token_embs * mask, axis=1)
    counts = np.maximum(np.sum(mask, axis=1), 1e-9)
    pooled = summed / counts
    return pooled / np.linalg.norm(pooled, axis=1, keepdims=True)

embs = np.array([
    [[1.0, 0.0], [3.0, 0.0], [99.0, 99.0]],  # Last token is padding!
])
mask = np.array([[1, 1, 0]])
print("Clean L2-normalized pooled embedding:", masked_mean_pool(embs, mask).round(3))`}
  libraryCode={`import torch

def create_mlm_inputs(token_ids, mask_token_id=103, mask_prob=0.15):
    torch.manual_seed(42)
    labels = token_ids.clone()
    probs = torch.full(token_ids.shape, mask_prob)
    masked_indices = torch.bernoulli(probs).bool()
    labels[~masked_indices] = -100  # Ignored by CrossEntropyLoss
    inputs = token_ids.clone()
    inputs[masked_indices] = mask_token_id
    return inputs, labels

ids = torch.tensor([[101, 2023, 2003, 1037, 2742, 102]])
inp, lbl = create_mlm_inputs(ids, mask_prob=0.35)
print("Masked input IDs:", inp.tolist())
print("MLM target labels:", lbl.tolist())`}

def mean_pool_single(vectors, mask):

    return np.sum(np.asarray(vectors, dtype=float) * m, axis=0) / np.maximum(np.sum(m), 1e-9)`}
