## Intuition: Predicting One Token at a Time—Efficiently

GPT models train on raw text by predicting token $t+1$ from tokens $1 \dots t$ across *every* position in parallel using a triangular causal mask.

At generation time, generating 500 new tokens naively recomputes Keys and Values for the entire growing prompt 500 times! Because causal masking guarantees earlier token Keys and Values **never depend on future tokens**, **KV Caching** stores past $(K, V)$ tensors in GPU memory so each new token computes attention using only its single new Query vector!

  Given logits $z \in \mathbb{R}^V$ and temperature $\tau > 0$:
  <Math tex="p_i = \text{softmax}(z / \tau)_i" display />
  - $\tau < 1$: sharpens toward greedy argmax (factual/code).
  - **Top-k:** keeps only the $k$ highest-logit tokens.
  - **Top-p (Nucleus):** keeps the smallest sorted set whose cumulative probability reaches $p$ (e.g., $0.9$), dynamically widening choices when uncertain and narrowing when confident.
</Callout>

def sample_probs(logits, temperature=1.0, top_k=0, top_p=1.0):
    scaled = np.asarray(logits, dtype=float) / max(1e-6, temperature)
    if top_k > 0:
        thresh = np.sort(scaled)[-top_k]
        scaled = np.where(scaled < thresh, -1e9, scaled)
    shifted = scaled - np.max(scaled)
    probs = np.exp(shifted)
    probs /= np.sum(probs)
    if top_p < 1.0:
        idx = np.argsort(probs)[::-1]
        cum = np.cumsum(probs[idx])
        remove = cum > top_p
        remove[0] = False  # Always keep top token
        keep_mask = np.ones_like(probs, dtype=bool)
        keep_mask[idx[remove]] = False
        probs = np.where(keep_mask, probs, 0.0)
        probs /= np.sum(probs)
    return probs

logits = np.array([4.0, 2.5, 1.0, -0.5, -2.0])
print("Temp=0.5 :", sample_probs(logits, temperature=0.5).round(3))
print("Top-p=0.8:", sample_probs(logits, top_p=0.8).round(3))`}
