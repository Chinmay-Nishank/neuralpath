## Intuition: Why Words Fail and Characters Are Too Long

Splitting text by spaces fails immediately on typos, rare compound words (`"unbelievably"`), code identifiers, and languages without spaces—blowing up vocabulary tables with `<UNK>` tokens. Splitting every character solves `<UNK>` but stretches a 1,000-word essay into 5,500 tokens, increasing attention cost $30\times$!

**<GlossaryTerm term="Byte-Pair Encoding">Byte-Pair Encoding (BPE)</GlossaryTerm>** strikes the sweet spot: start with raw UTF-8 bytes (`256` base tokens) and repeatedly merge the most frequent adjacent pair into a new subword token until reaching vocabulary budget (typically 32k–128k tokens).

<Callout type="warning" title="Tokenization Explains Classic LLM Quirks">
  Because models only ever see integer token IDs—not individual characters—tasks like counting letters inside `"strawberry"` or reversing arbitrary strings are harder than they look unless digits/letters are split finely.
</Callout>

<Callout type="math-deep-dive" title="Byte-Level BPE Merge Objective">
  At each merge iteration $k = 1 \dots V - 256$, BPE scans corpus bigrams and merges:
  <Math tex="(a^*, b^*) = \arg\max_{(a, b)} \text{count}(a, b)" display />
  Inference applies the exact ordered merge rules deterministically, guaranteeing zero unknown tokens on any valid UTF-8 input.
</Callout>

def get_stats(ids):
    return Counter(zip(ids, ids[1:]))

def merge_pair(ids, pair, new_id):
    out, i = [], 0
    while i < len(ids):
        if i < len(ids) - 1 and (ids[i], ids[i + 1]) == pair:
            out.append(new_id)
            i += 2
        else:
            out.append(ids[i])
            i += 1
    return out

text = "low lower lowest newer newest wider"
tokens = list(text.encode("utf-8"))
vocab = {i: bytes([i]) for i in range(256)}
merges = {}

for step in range(5):
    stats = get_stats(tokens)
    pair, freq = stats.most_common(1)[0]
    new_id = 256 + step
    merges[pair] = new_id
    vocab[new_id] = vocab[pair[0]] + vocab[pair[1]]
    tokens = merge_pair(tokens, pair, new_id)
    print(f"Merge {step+1}: {vocab[new_id]!r} (freq={freq}) -> token {new_id}")

print("Compressed length:", len(text.encode("utf-8")), "->", len(tokens), "tokens")`}
