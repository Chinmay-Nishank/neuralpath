## Intuition: Words Change Meaning in Context

Consider two nearly identical sentences:
- *"The animal didn't cross the street because **it** was too **tired**."*
- *"The animal didn't cross the street because **it** was too **wide**."*

What does **"it"** refer to? Changing a single adjective at the end flips **"it"** from *animal* to *street*. Static lookup embeddings assign the exact same vector to `"it"` in both sentences.

<GlossaryTerm term="Self-Attention">Self-attention</GlossaryTerm> solves this in $O(1)$ sequential path length: every token emits a **Query** (*"what am I looking for?"*), a **Key** (*"what do I advertise?"*), and a **Value** (*"what content do I share if selected?"*).

## Step-by-Step Mechanics of Scaled Dot-Product Attention

Given an input sequence matrix $X \in \mathbb{R}^{n \times d_{\text{model}}}$, learned projection matrices $W_Q, W_K \in \mathbb{R}^{d_{\text{model}} \times d_k}$ and $W_V \in \mathbb{R}^{d_{\text{model}} \times d_v}$ produce:

<Math tex="Q = X W_Q, \qquad K = X W_K, \qquad V = X W_V" display />

Each query vector $q_i$ scores compatibility with every key $k_j$ via dot product, scales by $\sqrt{d_k}$, optionally applies a causal mask $M$ ($-\infty$ above the diagonal), normalizes via softmax, and blends Value rows:

<Math tex="\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{Q K^T}{\sqrt{d_k}} + M\right) V" display />

<Callout type="math-deep-dive" title="Why Divide by √d_k?">
  Suppose components of $q$ and $k$ are independent with mean $0$ and variance $1$. Their dot product $\sum_{i=1}^{d_k} q_i k_i$ has mean $0$ and variance $d_k$. When $d_k = 128$, dot products frequently hit $\pm 30$, pushing $\text{softmax}$ into saturated regions where gradients vanish toward zero. Dividing by $\sqrt{d_k}$ restores unit variance regardless of head dimension.
</Callout>

<Callout type="tip" title="Modern Practice: GQA and FlashAttention">
  Production Transformers like Llama 3/4 and Qwen use **Grouped-Query Attention (<GlossaryTerm term="Grouped-Query Attention">GQA</GlossaryTerm>)** so multiple Query heads share Key/Value heads, cutting KV-cache memory during inference, while **FlashAttention** computes the exact same equation tile-by-tile in SRAM without materializing the $n \times n$ matrix in slow HBM memory.
</Callout>

def softmax(x, axis=-1):
    shifted = x - np.max(x, axis=axis, keepdims=True)
    exp_x = np.exp(shifted)
    return exp_x / np.sum(exp_x, axis=axis, keepdims=True)

def self_attention(Q, K, V, causal=False):
    d_k = Q.shape[-1]
    scores = (Q @ K.T) / np.sqrt(d_k)
    if causal:
        n = Q.shape[0]
        mask = np.triu(np.ones((n, n), dtype=bool), k=1)
        scores = np.where(mask, -1e9, scores)
    weights = softmax(scores, axis=-1)
    return weights @ V, weights

rng = np.random.default_rng(7)
X = rng.normal(size=(4, 8))
W_Q = rng.normal(scale=0.5, size=(8, 4))
W_K = rng.normal(scale=0.5, size=(8, 4))
W_V = rng.normal(scale=0.5, size=(8, 4))

out, attn = self_attention(X @ W_Q, X @ W_K, X @ W_V, causal=True)
print("Causal attention weights (row sums == 1):")
print(np.round(attn, 3))
print("Output shape:", out.shape)`}

import torch.nn as nn
import torch.nn.functional as F

class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model=64, num_heads=4):
        super().__init__()
        assert d_model % num_heads == 0
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        self.qkv = nn.Linear(d_model, 3 * d_model, bias=False)
        self.out_proj = nn.Linear(d_model, d_model, bias=False)

    def forward(self, x, is_causal=True):
        B, T, C = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)
        q = q.view(B, T, self.num_heads, self.head_dim).transpose(1, 2)
        k = k.view(B, T, self.num_heads, self.head_dim).transpose(1, 2)
        v = v.view(B, T, self.num_heads, self.head_dim).transpose(1, 2)
        y = F.scaled_dot_product_attention(q, k, v, is_causal=is_causal)
        return self.out_proj(y.transpose(1, 2).contiguous().view(B, T, C))
