## Intuition: Reading One Token at a Time with Hidden Memory

An RNN processes a sequence $x_1, x_2, \dots, x_T$ sequentially, updating a recurrent hidden summary $h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$.

Two critical bottlenecks motivated Transformers:
1. **Sequential Bottleneck:** step $t$ cannot run until step $t-1$ finishes, blocking GPU parallelization across tokens.
2. **Vanishing Gradients:** backpropagating 100 steps multiplies $W_h^T$ 100 times—shrinking gradients toward zero if eigenvalues $< 1$, or exploding if $> 1$.

<Viz type="backprop" />

<Callout type="math-deep-dive" title="How LSTM Cell States Create an Additive Memory Highway">
  Long Short-Term Memory (LSTM) introduces an explicit **cell state** $c_t$ updated additively via forget gate $f_t$ and input gate $i_t$:

  <Math tex="c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t" display />

  Just like ResNet skip connections, when $f_t \approx 1$, gradients flow backward across dozens of steps without multiplicative decay!
</Callout>

# 1-layer Elman RNN forward unroll over 4 steps
rng = np.random.default_rng(7)
T, d_in, d_h = 4, 3, 5
X = rng.normal(size=(T, d_in))
Wx = rng.normal(0, 0.3, size=(d_in, d_h))
Wh = rng.normal(0, 0.3, size=(d_h, d_h))
b = np.zeros(d_h)

h = np.zeros(d_h)
states = []
for t in range(T):

print("Unrolled hidden states shape:", np.array(states).shape)

def clip_grad_norm(grad, max_norm=1.0):
    g = np.asarray(grad, dtype=float)
    norm = float(np.linalg.norm(g))
    if norm > max_norm:
