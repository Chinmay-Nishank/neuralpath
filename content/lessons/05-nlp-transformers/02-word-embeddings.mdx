## Intuition: You Shall Know a Word by the Company It Keeps

One-hot vectors assign orthogonal unit axes to every token—meaning `"cat"` and `"kitten"` sit just as far apart as `"cat"` and `"refrigerator"`.

**<GlossaryTerm term="Embedding">Embeddings</GlossaryTerm>** solve this by mapping each token ID $i \in \{0 \dots V-1\}$ to a dense $d$-dimensional row vector inside an embedding matrix $E \in \mathbb{R}^{V \times d}$. Training via Skip-Gram (Word2Vec) or next-token prediction automatically pulls words appearing in similar contexts into nearby geometric regions!

<Callout type="math-deep-dive" title="Embedding Lookup = One-Hot Matrix Multiply">
  Selecting row $i$ from $E \in \mathbb{R}^{V \times d}$ is mathematically equivalent to multiplying a one-hot row vector $e_i^T$ by $E$, costing $O(d)$ memory access instead of $O(Vd)$ arithmetic.
</Callout>

vocab = {"king": 0, "queen": 1, "man": 2, "woman": 3, "apple": 4}

    [0.95, 0.85, 0.05],   # king

def cos_sim(a, b):
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

target = E[vocab["king"]] - E[vocab["man"]] + E[vocab["woman"]]
ranked = sorted(

)
print("Analogy king - man + woman top match:", ranked[0][0], round(ranked[0][1], 4))`}

def nearest_neighbor(query_vec, matrix):
    q = np.asarray(query_vec, dtype=float)
    M = np.asarray(matrix, dtype=float)
    q_norm = q / max(1e-12, float(np.linalg.norm(q)))
    m_norms = np.linalg.norm(M, axis=1, keepdims=True)
    M_norm = M / np.maximum(m_norms, 1e-12)
    sims = M_norm @ q_norm
    return int(np.argmax(sims))`}
