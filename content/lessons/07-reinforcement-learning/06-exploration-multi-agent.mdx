## Intuition: Stopping A/B Waste Early

Suppose you deploy three candidate LLM prompts or UI designs. Classical A/B testing sends 33% of traffic equally forever until a fixed horizon—wasting thousands of interactions on inferior variants.

**Multi-Armed Bandits** dynamically shift traffic toward stronger arms while still sampling uncertain ones just enough to verify they aren't hidden winners:
- **$\varepsilon$-greedy:** explores blindly with constant probability $\varepsilon$, wasting samples on known losers forever.
- **UCB1 (Optimism in the Face of Uncertainty):** adds an uncertainty bonus $\propto \sqrt{\frac{\ln t}{N_a}}$ that shrinks as arm $a$ is tried often.
- **Thompson Sampling:** maintains a Beta posterior per arm and picks whichever arm draws the highest random sample!

<Viz type="rl-gridworld" />

<Callout type="math-deep-dive" title="UCB1 Selection Formula">
  At round $t$, pick arm $a$:
  <Math tex="a_t = \arg\max_a \left(\hat{\mu}_a + c\sqrt{\frac{\ln t}{N_a}}\right)" display />
  Unlike constant $\varepsilon$-greedy (linear regret), both UCB1 and Thompson Sampling achieve logarithmic regret $O(\ln T)$.
</Callout>

  code={`import numpy as np

true_rates = [0.25, 0.55, 0.72]  # Arm 2 is optimal

def run_ucb1(rounds=400, seed=42):
    counts = np.ones(3)
    values = np.zeros(3)
    regret = 0.0
    rng = np.random.default_rng(seed)
    for t in range(1, rounds + 1):
        ucb = values + np.sqrt(2.0 * np.log(t) / counts)
        arm = int(np.argmax(ucb))
        reward = float(rng.random() < true_rates[arm])
        counts[arm] += 1
        values[arm] += (reward - values[arm]) / counts[arm]
        regret += max(true_rates) - true_rates[arm]
    return counts, round(regret, 2)

counts, reg = run_ucb1()
print("UCB1 arm pulls:", counts.astype(int).tolist(), "| Total regret:", reg)`}

# Bayesian Thompson Sampling with Beta(alpha, beta) priors
true_rates = [0.25, 0.55, 0.72]
alpha = np.ones(3)
beta = np.ones(3)
rng = np.random.default_rng(7)
pulls = np.zeros(3, dtype=int)

for _ in range(400):
    samples = rng.beta(alpha, beta)
    arm = int(np.argmax(samples))
    reward = int(rng.random() < true_rates[arm])
    alpha[arm] += reward
    beta[arm] += (1 - reward)
    pulls[arm] += 1

print("Thompson Sampling pulls:", pulls.tolist(), "| Best arm share:", round(float(pulls[2] / 400), 3))`}
