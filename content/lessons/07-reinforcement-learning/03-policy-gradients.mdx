## Intuition: Reinforce Lucky Trajectories, Suppress Bad Ones

Value-based Q-learning struggles with continuous robotics control (`steer = +0.34 radians`) because computing $\arg\max_a Q(s, a)$ over continuous actions is intractable.

**Policy Gradient** methods parameterize the policy $\pi_\theta(a \mid s)$ directly! By the **REINFORCE** log-derivative theorem, increasing the log-probability of actions weighted by how much better they scored than expected (**Advantage** $A_t = R_t - b(s_t)$) moves parameters uphill in expected return!

<Viz type="rl-gridworld" />

<Callout type="math-deep-dive" title="Policy Gradient Theorem with Variance-Reducing Baseline">
  <Math tex="\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\!\left[\sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\,\big(G_t - V_\phi(s_t)\big)\right]" display />
  Subtracting any state-dependent baseline $V_\phi(s_t)$ leaves the expectation **unbiased** while drastically shrinking variance—turning noisy full-episode returns into centered positive/negative advantage signals!
</Callout>

policy = nn.Sequential(nn.Linear(4, 32), nn.Tanh(), nn.Linear(32, 2))
critic = nn.Sequential(nn.Linear(4, 32), nn.Tanh(), nn.Linear(32, 1))

states = torch.randn(6, 4)
actions = torch.tensor([0, 1, 0, 1, 1, 0])
returns = torch.tensor([2.5, 4.0, 1.2, 3.8, 4.1, 0.9])

dist = Categorical(logits=policy(states))
log_probs = dist.log_prob(actions)
values = critic(states).squeeze(-1)

advantage = (returns - values.detach())
actor_loss = -(log_probs * advantage).mean()

total_loss = actor_loss + 0.5 * critic_loss - 0.01 * entropy_bonus
print("Actor loss:", round(actor_loss.item(), 3), "Critic loss:", round(critic_loss.item(), 3))`}

def normalize_advantages(returns, baselines):
    adv = np.asarray(returns, dtype=float) - np.asarray(baselines, dtype=float)
    return (adv - np.mean(adv)) / (np.std(adv) + 1e-8)`}
