## Intuition: Never Step Too Far From What Collected the Data

In supervised learning, a slightly oversized learning rate causes a noisy step, yet the training dataset remains intact. In RL, a bad parameter update ruins the **policy itself**, which immediately collects terrible future rollouts from which the agent never recovers!

**<GlossaryTerm term="PPO">PPO</GlossaryTerm>** prevents catastrophic policy swings simply and cheaply: measure the probability ratio $r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\theta_{\text{old}}}(a_t \mid s_t)}$ and **clip** updates outside $[1 - \epsilon, 1 + \epsilon]$ (typically $\epsilon = 0.2$), letting us safely reuse each rollout batch for multiple gradient epochs!

<Viz type="rl-gridworld" />

<Callout type="math-deep-dive" title="PPO Clipped Surrogate & GAE Equations">
  PPO maximizes the pessimistic lower bound:
  <Math tex="L^{\text{CLIP}}(\theta) = \mathbb{E}_t\Big[\min\!\big(r_t(\theta) \hat{A}_t,\; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t\big)\Big]" display />
  Meanwhile, **Generalized Advantage Estimation (GAE)** blends multi-step TD errors $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ exponentially with $\lambda \in [0, 1]$ (typically $0.95$):
  <Math tex="\hat{A}_t^{\text{GAE}} = \delta_t + (\gamma\lambda)\hat{A}_{t+1}^{\text{GAE}}" display />
</Callout>

def compute_gae(rewards, values, next_value, gamma=0.99, lam=0.95):
    T = len(rewards)
    adv = np.zeros(T)
    last_gae = 0.0
    for t in reversed(range(T)):
        v_next = next_value if t == T - 1 else values[t + 1]
        delta = rewards[t] + gamma * v_next - values[t]
        last_gae = delta + gamma * lam * last_gae
        adv[t] = last_gae
    return adv

rewards = np.array([0.0, 0.0, 1.0, 2.0])
values = np.array([0.4, 0.8, 1.5, 1.8])
print("GAE advantages:", np.round(compute_gae(rewards, values, next_value=0.0), 3))`}

def ppo_clipped_loss(new_log_probs, old_log_probs, advantages, eps=0.2):
    ratio = torch.exp(new_log_probs - old_log_probs)
    unclipped = ratio * advantages
    clipped = torch.clamp(ratio, 1.0 - eps, 1.0 + eps) * advantages
    return -torch.min(unclipped, clipped).mean()

old_lp = torch.tensor([-1.2, -0.8, -1.5])
new_lp = torch.tensor([-0.6, -1.0, -1.4])  # ratio[0] = exp(0.6) = 1.82 -> clipped!
adv = torch.tensor([1.5, -1.0, 0.5])
print("PPO surrogate loss:", round(ppo_clipped_loss(new_lp, old_lp, adv).item(), 4))`}
