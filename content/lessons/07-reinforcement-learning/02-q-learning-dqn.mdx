## Intuition: Learning Without a Rulebook

In real games or robotics, you rarely possess the transition probability table $P(s' \mid s, a)$ required by Bellman Value Iteration. **<GlossaryTerm term="Q-Learning">Q-Learning</GlossaryTerm>** learns action-values $Q(s, a)$ purely from trial-and-error experience tuples $(s, a, r, s')$:

<Math tex="Q(s, a) \leftarrow Q(s, a) + \alpha \Big[\underbrace{r + \gamma \max_{a'} Q(s', a')}_{\text{TD Target}} - Q(s, a)\Big]" display />

When state spaces grow too huge for tables (Atari pixels, continuous sensors), **DQN** replaces the table with a neural network $Q_\theta(s, a)$. Two fixes prevent catastrophic divergence: **Experience Replay** (shuffling past transitions to break temporal correlation) and a frozen **Target Network** $Q_{\theta^-}$ updated slowly so the TD target stops chasing itself!

<Callout type="math-deep-dive" title="On-Policy SARSA vs. Off-Policy Q-Learning">
  - **Q-Learning** uses $\max_{a'} Q(s', a')$ regardless of what exploratory random action the agent takes next (*off-policy*).
  - **SARSA** updates using the action $a'$ actually sampled by the exploratory policy (*on-policy*), learning safer paths further away from cliff hazards!

# 5-state corridor: state 0..3 -> right moves +1, left moves -1; state 4 is Goal (+10)
Q = np.zeros((5, 2))  # actions: 0=left, 1=right
alpha, gamma, eps = 0.2, 0.9, 0.2
rng = np.random.default_rng(7)

for _ in range(150):
    s = 0
    for _ in range(20):
        a = int(rng.integers(2)) if rng.random() < eps else int(np.argmax(Q[s]))
        ns = max(0, s - 1) if a == 0 else min(4, s + 1)
        r = 10.0 if ns == 4 else -0.1
        done = (ns == 4)
        td_target = r + (0.0 if done else gamma * np.max(Q[ns]))
        Q[s, a] += alpha * (td_target - Q[s, a])
        s = ns
        if done:
            break

print("Learned Q-table (states 0..3):\n", np.round(Q[:4], 2))`}

import torch.nn as nn

q_net = nn.Sequential(nn.Linear(4, 32), nn.ReLU(), nn.Linear(32, 2))

target_net.load_state_dict(q_net.state_dict())

states = torch.randn(8, 4)
actions = torch.tensor([0, 1, 1, 0, 1, 0, 0, 1])
rewards = torch.tensor([0.0, 1.0, 0.0, -1.0, 1.0, 0.0, 0.0, 1.0])
next_states = torch.randn(8, 4)
dones = torch.tensor([0., 1., 0., 1., 0., 0., 0., 1.])

q_vals = q_net(states).gather(1, actions.unsqueeze(1)).squeeze(1)
with torch.no_grad():

    targets = rewards + 0.99 * (1.0 - dones) * next_max

loss = nn.SmoothL1Loss()(q_vals, targets)
print("DQN Huber TD loss:", round(loss.item(), 4))`}
