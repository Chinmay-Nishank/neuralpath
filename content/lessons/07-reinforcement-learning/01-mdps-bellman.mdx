## Intuition: Actions Have Delayed Consequences

In supervised learning, every input $x_i$ has an immediate label $y_i$. In **Reinforcement Learning (RL)**, an agent acts inside an environment over time: steering left now might cost $-0.1$ energy while setting up a $+10$ reward twenty steps later!

A **<GlossaryTerm term="Markov Decision Process">Markov Decision Process (MDP)</GlossaryTerm>** captures sequential decision making with five elements $(S, A, P, R, \gamma)$:
- **Markov Property:** the next state depends *only* on the current state and action—never on distant history.
- **Discount Factor $\gamma \in [0, 1)$:** values near $0$ care only about immediate reward; values near $0.99$ plan long horizons.

<Callout type="math-deep-dive" title="The Bellman Optimality Equation">
  The optimal state-value $V^*(s)$ satisfies a recursive fixed-point identity:

  <Math tex="V^*(s) = \max_{a \in A} \sum_{s'} P(s' \mid s, a)\Big[R(s, a, s') + \gamma V^*(s')\Big]" display />

  Repeatedly applying this backup (**Value Iteration**) contracts toward the unique optimal value table at rate $\gamma$.
</Callout>

        # Actions: left (max(0, s-1)) or right (s+1)
