## Intuition: Teaching Helpful, Safe, and Reasoning Behavior

Pretraining teaches next-token probability on internet text; **post-training alignment** teaches a model *how* to answer helpfully, refuse harm, and verify multi-step reasoning.

Three milestones define modern LLM post-training:
1. **Classic RLHF (InstructGPT):** Train SFT -> train a separate **Reward Model** on human preference pairs -> run **PPO** while adding a KL penalty against the reference SFT policy so the model doesn't game reward with gibberish.
2. **<GlossaryTerm term="DPO">DPO (Direct Preference Optimization)</GlossaryTerm>:** Proves mathematically that the optimal RLHF policy has a closed-form mapping to the reward function—eliminating both the separate Reward Model and PPO loop completely!
3. **GRPO (Group Relative Policy Optimization):** Powers reasoning models (like DeepSeek-R1): sample a **group** of $G$ rollouts per prompt, score them against deterministic code/math verifiers (or reward models), and normalize advantages relative to the **group mean**—removing the memory-heavy Critic network entirely!

<Callout type="math-deep-dive" title="DPO Loss vs. GRPO Group Advantage">
  For chosen response $y_w$ and rejected response $y_l$ given reference policy $\pi_{\text{ref}}$:
  <Math tex="\mathcal{L}_{\text{DPO}}(\theta) = -\log \sigma\!\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}\right)" display />
  In **GRPO**, given group rewards $\{r_1, \dots, r_G\}$ for prompt $x$, each rollout gets advantage $A_i = (r_i - \bar{r}) / (\sigma_r + \epsilon)$ with zero critic model VRAM!
</Callout>

# 1. DPO preference margin loss
def dpo_loss(pi_w, pi_l, ref_w, ref_l, beta=0.1):
    # Inputs are sequence sum log-probabilities
    logits = beta * ((pi_w - ref_w) - (pi_l - ref_l))
    return float(-np.log(1.0 / (1.0 + np.exp(-logits))))

# Model assigns higher relative likelihood to chosen y_w than rejected y_l
print("DPO loss (good separation):", round(dpo_loss(-12.0, -25.0, -14.0, -18.0, beta=0.1), 4))

# 2. GRPO critic-free group normalization across 4 sampled reasoning chains
group_rewards = np.array([1.0, 0.0, 1.0, 0.0])  # e.g., verifiable unit test pass/fail
grpo_adv = (group_rewards - group_rewards.mean()) / (group_rewards.std() + 1e-8)
print("GRPO group advantages:", np.round(grpo_adv, 3))`}
