## Intuition: Untangling Polysemantic Neurons via Dictionary Learning

If you inspect a single neuron inside GPT or Claude, it rarely represents one clean idea—it might fire simultaneously for *base64 strings*, *French poetry*, and *SQL quotes*! Why? Because neural networks pack far more concepts than neurons by storing concepts as nearly-orthogonal directions (**superposition**), making individual neurons **polysemantic**.

**<GlossaryTerm term="Sparse Autoencoder">Sparse Autoencoders (SAEs)</GlossaryTerm>** reverse superposition using dictionary learning: project a dense $d$-dimensional residual activation $x$ up into a much wider sparse latent layer $z \in \mathbb{R}^{M}$ ($M \gg d$) with an L1 (or Top-$K$) sparsity constraint so only ~20–50 features fire per token! Each sparse dictionary direction isolates clean **monosemantic features** (such as *deception*, *code syntax errors*, or *Golden Gate Bridge*), letting safety teams monitor hidden states or steer behavior cleanly!

<Callout type="note" title="From Research Demos to Open Interpretability Suites">
  Open-weight SAE suites like Google DeepMind's **Gemma Scope** and production attribution graphs allow auditors to trace internal reasoning circuits and catch misaligned intents *before* unsafe tokens are even sampled—though researchers actively validate whether extracted SAE directions are causally faithful vs. reconstruction artifacts.
</Callout>

<Callout type="math-deep-dive" title="Overcomplete SAE Objective">
  Given hidden residual activation $x \in \mathbb{R}^d$, encoder $W_{\text{enc}} \in \mathbb{R}^{d \times M}$, and unit-norm decoder dictionary columns $W_{\text{dec}} \in \mathbb{R}^{M \times d}$ ($M \gg d$):

  <Math tex="f(x) = \text{ReLU}\!\big((x - b_{\text{dec}})W_{\text{enc}} + b_{\text{enc}}\big), \qquad \hat{x} = f(x) W_{\text{dec}} + b_{\text{dec}}" display />
  <Math tex="\mathcal{L}_{\text{SAE}} = \|x - \hat{x}\|_2^2 + \lambda \|f(x)\|_1" display />
</Callout>

angles = np.array([0.0, np.pi/4, np.pi/2, 3*np.pi/4])

# Activate concept #2 only
sparse_code = np.array([0.0, 0.0, 1.5, 0.0])
residual = D @ sparse_code
# Steering: clamp concept #0 up by +2.0 directly in residual space!
steered = residual + 2.0 * D[:, 0]
print("Original residual:", np.round(residual, 3))
print("Steered residual :", np.round(steered, 3))`}
  libraryCode={`import torch
import torch.nn as nn

class SparseAutoencoder(nn.Module):
    def __init__(self, d_model=16, d_sae=64):
        super().__init__()
        self.enc = nn.Linear(d_model, d_sae)
        self.dec = nn.Linear(d_sae, d_model)

    def forward(self, x):
        feats = torch.relu(self.enc(x))
        recon = self.dec(feats)
        return recon, feats

sae = SparseAutoencoder(16, 64)
opt = torch.optim.Adam(sae.parameters(), lr=1e-2)
x = torch.randn(32, 16)
recon, feats = sae(x)
loss = ((x - recon) ** 2).mean() + 0.05 * feats.abs().mean()
loss.backward(); opt.step()
active_frac = (feats > 0).float().mean().item()
print(f"SAE Loss={loss.item():.4f} | Active feature fraction={active_frac:.2%}")`}

def steer_activation(h, feature_dir, strength=2.0):
    d = np.asarray(feature_dir, dtype=float)
    unit_d = d / max(1e-12, float(np.linalg.norm(d)))
    return np.asarray(h, dtype=float) + float(strength) * unit_d`}
