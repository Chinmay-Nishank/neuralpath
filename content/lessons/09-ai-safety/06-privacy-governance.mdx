## Intuition: Protecting Individual Training Records

Large models memorize rare verbatim secrets (SSNs, API keys, private medical notes) seen during training—making them vulnerable to **membership inference** or training-data extraction attacks.

**<GlossaryTerm term="Differential Privacy">Differential Privacy (DP)</GlossaryTerm>** gives a rigorous mathematical promise: whether *your* personal record is included in or removed from the training dataset changes the model's output probabilities by at most $e^\epsilon$. In **DP-SGD**, we achieve this in two steps per sample:
1. **Clip per-sample gradients** to norm $C$ (bounding any single person's influence).
2. **Add calibrated Gaussian noise** $\mathcal{N}(0, \sigma^2 C^2 I)$ before averaging the batch update.

<Viz type="probability" />

<Callout type="math-deep-dive" title="Randomized Response & (ε, δ)-Differential Privacy">
  A randomized algorithm $\mathcal{M}$ is $(\epsilon, \delta)$-differentially private if for any two datasets $D, D'$ differing in one single user record and any output event $S$:
  <Math tex="\Pr[\mathcal{M}(D) \in S] \le e^\epsilon \Pr[\mathcal{M}(D') \in S] + \delta" display />
  Smaller $\epsilon$ gives stronger privacy at the cost of extra gradient noise.
</Callout>

def dp_sgd_step(per_sample_grads, clip_norm=1.0, noise_mult=0.5, seed=42):
    # Clip EVERY sample's gradient individually before averaging!
    clipped = []
    for g in per_sample_grads:
        norm = float(np.linalg.norm(g))
        scale = min(1.0, clip_norm / max(1e-12, norm))
        clipped.append(g * scale)
    avg_grad = np.mean(clipped, axis=0)
    rng = np.random.default_rng(seed)
    noise = rng.normal(0.0, noise_mult * clip_norm / len(per_sample_grads), size=avg_grad.shape)
    return avg_grad + noise

grads = np.array([[0.2, 0.3], [50.0, -50.0], [0.1, -0.2]])  # Sample 1 is an extreme outlier!
private_grad = dp_sgd_step(grads, clip_norm=1.0, noise_mult=0.4)
print("DP-SGD bounded update:", np.round(private_grad, 4))`}

def clip_per_sample_grad(grad, max_norm=1.0):
    g = np.asarray(grad, dtype=float)
    norm = float(np.linalg.norm(g))
    if norm > max_norm:
        return g * (max_norm / norm)
