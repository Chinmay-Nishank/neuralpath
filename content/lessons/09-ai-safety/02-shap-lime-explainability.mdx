## Intuition: Fairly Crediting Every Feature for a Single Decision

When a loan classifier rejects an applicant with probability `0.78`, stakeholders ask *"why this specific prediction?"*

Three core attribution tools answer different questions:
1. **Permutation Importance (Global):** randomly shuffle one feature column on validation data and measure how much accuracy drops—exposing which features the model relies on globally.
2. **LIME (Local Surrogate):** generate synthetic neighbors around one specific point $x$, query the black-box model, and fit a simple interpretable linear ridge model locally.
3. **<GlossaryTerm term="SHAP">SHAP (Shapley Values)</GlossaryTerm>:** averages each feature's marginal contribution across *all possible subsets (coalitions)* of co-occurring features—the unique game-theoretic solution guaranteeing exact additivity:

<Math tex="f(x) = \mathbb{E}[f(X)] + \sum_{j=1}^d \phi_j(x)" display />

<CodeRunner
  title="Exact Shapley Attribution From Scratch & Permutation Importance"
  code={`import itertools, math, numpy as np

# Model: f(x) = 2.0*x0 + 3.0*x1 + 1.5*x0*x1 (non-linear interaction!)
def model_fn(x):
    return 2.0 * x[0] + 3.0 * x[1] + 1.5 * x[0] * x[1]

baseline = np.array([0.0, 0.0])
target = np.array([1.0, 2.0])
d = 2
shap_vals = np.zeros(d)

for j in range(d):
    others = [k for k in range(d) if k != j]
    for r in range(len(others) + 1):
        for subset in itertools.combinations(others, r):
            weight = math.factorial(len(subset)) * math.factorial(d - len(subset) - 1) / math.factorial(d)
            x_without = baseline.copy()
            for idx in subset:
                x_without[idx] = target[idx]
            x_with = x_without.copy()
            x_with[j] = target[j]
            shap_vals[j] += weight * (model_fn(x_with) - model_fn(x_without))

print("Base f(0):", model_fn(baseline), "| Target f(x):", model_fn(target))
print("Exact SHAP values:", np.round(shap_vals, 4), "| Sum == f(x) - f(0):", round(float(shap_vals.sum()), 4))`}
