## Intuition: Smooth Continuous Latent Maps

A plain autoencoder learns an encoder $E(x) \to z$ and decoder $D(z) \to \hat{x}$ with no rules on how $z$ is arranged—leaving disconnected holes in latent space so random samples $z \sim \mathcal{N}(0, I)$ decode to gibberish.

A **Variational Autoencoder (VAE)** predicts a *distribution* $(\mu, \log\sigma^2)$ per input and forces all encoded distributions close to a standard Gaussian prior $\mathcal{N}(0, I)$. Every modern image generator (Stable Diffusion, FLUX) runs inside a pretrained VAE's $8\times$-downsampled latent space!

<Viz type="embeddings" />

<Callout type="math-deep-dive" title="ELBO Objective & Reparameterization Trick">
  Sampling $z \sim \mathcal{N}(\mu, \sigma^2)$ directly blocks gradients wrt $\mu$ and $\sigma$. We move randomness to $\epsilon \sim \mathcal{N}(0, I)$:
  <Math tex="z = \mu + \sigma \odot \epsilon" display />
  Maximizing the Evidence Lower Bound (**ELBO**) minimizes reconstruction error plus closed-form Gaussian KL divergence:
  <Math tex="\mathcal{L}_{\text{VAE}} = \|x - \hat{x}\|_2^2 + \frac{1}{2} \sum_{j=1}^{d_z} \left(\mu_j^2 + \sigma_j^2 - \log \sigma_j^2 - 1\right)" display />
</Callout>

def vae_kl_loss(mu, log_var):
    # Closed-form KL(N(mu, exp(log_var)) || N(0, I)) summed over latent dims, averaged over batch
    kl_per_sample = -0.5 * np.sum(1.0 + log_var - mu**2 - np.exp(log_var), axis=-1)
    return float(np.mean(kl_per_sample))

mu = np.array([[0.0, 0.0], [1.5, -1.0]])
log_var = np.array([[0.0, 0.0], [-0.5, -0.5]])
print("KL when matching N(0, I):", round(vae_kl_loss(mu[:1], log_var[:1]), 6))
print("KL when shifted/narrow  :", round(vae_kl_loss(mu[1:], log_var[1:]), 4))`}

import torch.nn as nn

class SimpleVAE(nn.Module):
    def __init__(self, d_in=64, d_z=8):
        super().__init__()
        self.enc = nn.Linear(d_in, 32)
        self.mu = nn.Linear(32, d_z)
        self.logvar = nn.Linear(32, d_z)
        self.dec = nn.Sequential(nn.Linear(d_z, 32), nn.ReLU(), nn.Linear(32, d_in))

    def forward(self, x):
        h = torch.relu(self.enc(x))
        mu, logvar = self.mu(h), self.logvar(h)
        std = torch.exp(0.5 * logvar)
        z = mu + std * torch.randn_like(std)
        return self.dec(z), mu, logvar

vae = SimpleVAE()
recon, mu, lv = vae(torch.randn(4, 64))
print("VAE recon shape:", tuple(recon.shape), "Latent mu shape:", tuple(mu.shape))`}
