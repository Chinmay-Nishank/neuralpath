## Intuition: From Curved Denoising to Straight-Line Flows

Classical **DDPM** diffusion corrupts real data $x_0$ with Gaussian noise across many steps and trains a model to denoise step-by-step along curved stochastic trajectories—typically needing 20–50 steps at inference.

Modern systems (Stable Diffusion 3, FLUX, and frontier video generators) use **Flow Matching / Rectified Flows**: define a straight linear path from pure noise $x_1 \sim \mathcal{N}(0, I)$ to clean data $x_0$:

<Math tex="x_t = (1 - t) x_0 + t \, x_1, \qquad t \in [0, 1]" display />

Because the interpolation path is straight, a **Diffusion Transformer (DiT)** predicting velocity $v_\theta(x_t, t) \approx x_1 - x_0$ integrates smoothly from noise back to sharp images in just **4–20 Euler steps**!

<Callout type="math-deep-dive" title="Conditional Flow Matching Training Objective">
  Sample clean data $x_0$, Gaussian noise $x_1 \sim \mathcal{N}(0, I)$, and timestep $t \sim \mathcal{U}(0, 1)$. The exact target velocity along the straight path is $u_t = x_1 - x_0$:

  <Math tex="\mathcal{L}_{\text{CFM}}(\theta) = \mathbb{E}_{t, x_0, x_1} \Big[\big\| v_\theta((1 - t)x_0 + t x_1,\, t) - (x_1 - x_0) \big\|_2^2\Big]" display />
</Callout>

# Forward linear interpolation and backward Euler integration check
x0 = np.array([2.0, -1.0])   # Clean data point
x1 = np.array([-1.5, 2.5])   # Gaussian noise sample
true_velocity = x1 - x0

# Integrate backward from t=1 (noise) to t=0 (data) in 10 Euler steps
x_cur = x1.copy()
dt = 1.0 / 10
for _ in range(10):
    # Perfect velocity oracle moves straight toward x0
    x_cur = x_cur - dt * true_velocity

print("Target x0:", x0)
print("Recovered x0 after 10 Euler steps:", np.round(x_cur, 6))`}
  libraryCode={`import torch
import torch.nn as nn

class TinyVelocityNet(nn.Module):
    def __init__(self, d=2):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(d + 1, 32), nn.SiLU(), nn.Linear(32, d))

    def forward(self, x_t, t):
        return self.net(torch.cat([x_t, t], dim=-1))

model = TinyVelocityNet()
opt = torch.optim.AdamW(model.parameters(), lr=1e-2)
x0 = torch.tensor([[1.0, 1.0], [-1.0, -1.0]] * 8)

for _ in range(30):
    t = torch.rand(len(x0), 1)
    x1 = torch.randn_like(x0)
    x_t = (1.0 - t) * x0 + t * x1
    v_pred = model(x_t, t)
    loss = ((v_pred - (x1 - x0)) ** 2).mean()
    opt.zero_grad(); loss.backward(); opt.step()

print("Flow matching training step loss:", round(loss.item(), 4))`}
