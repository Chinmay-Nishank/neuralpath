## Intuition: Power Laws & Sparse Active Compute

Pretraining loss drops smoothly as a **power law** in compute, dataset size, and parameter count. **Chinchilla scaling** (Hoffmann et al., 2022) showed that to minimize pretraining loss for a fixed FLOP budget $C \approx 6 N D$, model size $N$ and training tokens $D$ should scale *equally*—roughly **20 tokens per parameter** (e.g., 1.4T tokens for 70B).

In production, however, smaller models trained far past Chinchilla optimality (e.g., 8B parameters on 15T tokens) serve orders of magnitude faster! Better still: **<GlossaryTerm term="Mixture of Experts">Mixture-of-Experts (MoE)</GlossaryTerm>** replaces each dense FFN with $E$ parallel expert FFNs and routes each token to only the **top-2** experts—giving 100B+ total knowledge capacity at ~15B active FLOPs per token!

  Chinchilla models irreducible entropy plus parameter/data bottlenecks:
  <Math tex="L(N, D) = E + \frac{A}{N^\alpha} + \frac{B}{D^\beta}" display />
  In MoE layers, a lightweight linear router computes gating probabilities $g(x) = \text{softmax}(x W_g)$, keeps top-$k$ experts $\mathcal{T}$, and adds an auxiliary **load-balancing loss** so every expert processes equal token volume.

def chinchilla_estimate(params_b, tokens_t):
    N = params_b * 1e9
    D = tokens_t * 1e12
    flops = 6.0 * N * D
    ratio = D / N
    return flops, ratio

  libraryCode={`import torch
import torch.nn as nn
import torch.nn.functional as F

class Top2MoE(nn.Module):
    def __init__(self, d_model=32, num_experts=4, top_k=2):
        super().__init__()
        self.top_k = top_k
        self.router = nn.Linear(d_model, num_experts, bias=False)
        self.experts = nn.ModuleList([
            nn.Sequential(nn.Linear(d_model, d_model * 2), nn.SiLU(), nn.Linear(d_model * 2, d_model))
            for _ in range(num_experts)
        ])

    def forward(self, x):
        # x: (N_tokens, d_model)
        logits = self.router(x)
        weights, indices = torch.topk(F.softmax(logits, dim=-1), self.top_k, dim=-1)
        weights = weights / weights.sum(dim=-1, keepdim=True)
        out = torch.zeros_like(x)
        for k_idx in range(self.top_k):
            for e_id, expert in enumerate(self.experts):
                mask = (indices[:, k_idx] == e_id)
                if mask.any():
                    out[mask] += weights[mask, k_idx:k_idx+1] * expert(x[mask])
        return out

moe = Top2MoE()
print("Sparse MoE output shape:", tuple(moe(torch.randn(10, 32)).shape))`}
