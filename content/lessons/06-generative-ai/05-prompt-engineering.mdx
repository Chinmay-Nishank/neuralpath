## Intuition: Treat Prompts Like Typed APIs, Not Magic Spells

Unstructured prompts asking *"please output JSON only"* frequently break downstream parsers with conversational filler (`"Here is your JSON: ..."`).

Modern production systems rely on three engineering habits:
1. **Constrained Structured Outputs:** Pass a formal JSON Schema (via provider API `response_format` or vLLM/SGLang grammar decoding) so invalid syntax is impossible at token sampling time, then validate with **Pydantic** or **Zod**.
2. **Clear Delimiters:** Wrap untrusted user text inside XML/markdown tags (`<user_document>...</user_document>`) so instructions and data don't blur.
3. **Few-Shot Exemplars & Verification:** Two crisp `(input -> output)` examples often outperform paragraphs of vague prose rules.

<Viz type="tokenizer" />

<Callout type="note" title="Do You Actually Need Fine-Tuning?">
  Never fine-tune a model solely to enforce JSON keys or output formatting—native constrained decoding enforces schemas deterministically at zero training cost.
</Callout>

<Callout type="math-deep-dive" title="Why Chain-of-Thought Unlocks Multi-Step Computation">
  An autoregressive Transformer allocates fixed depth (e.g., 32–80 layers) per single forward pass. Asking for intermediate scratchpad reasoning tokens effectively grants the model $O(T)$ sequential computation steps before committing to a final answer token.
</Callout>

def build_prompt(task, doc, examples):
    ex_text = "\\n".join(
        f"Example Input: {ex['in']}\\nExample JSON: {json.dumps(ex['out'])}"
        for ex in examples
    )
    return (
        f"Task: {task}\\n\\n{ex_text}\\n\\n"
        f"<document>\\n{doc}\\n</document>\\nRespond strictly with valid JSON."
    )

def parse_ticket(raw_json):
    data = json.loads(raw_json)
    assert isinstance(data.get("severity"), str) and data["severity"] in {"low", "med", "high"}
    assert isinstance(data.get("tags"), list)
    return data

prompt = build_prompt(
    "Classify bug report.",
    "Checkout returns 500 on Safari.",
    [{"in": "Typo in footer", "out": {"severity": "low", "tags": ["ui"]}}]
)
print(prompt)
print("Validated:", parse_ticket('{"severity": "high", "tags": ["checkout", "500"]}'))`}

def extract_valid_json(text):
    cleaned = text.strip()
    fence = chr(96) * 3
    if cleaned.startswith(fence):
        lines = cleaned.splitlines()
        cleaned = chr(10).join(lines[1:-1] if lines[-1].strip() == fence else lines[1:])
    return json.loads(cleaned)`}
