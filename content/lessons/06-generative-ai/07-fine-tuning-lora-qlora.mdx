## Intuition: Freezing the Giant, Tuning Low-Rank Deltas

Full fine-tuning of a 70B LLM requires >1 TB of VRAM just for FP32 optimizer states and gradients. Yet Aghajanyan et al. and Hu et al. showed that task-specific weight updates live in a surprisingly tiny **low-rank subspace**!

**<GlossaryTerm term="LoRA">LoRA</GlossaryTerm>** freezes the giant pretrained matrix $W_0 \in \mathbb{R}^{d \times k}$ and injects two tiny trainable matrices $B \in \mathbb{R}^{d \times r}$ and $A \in \mathbb{R}^{r \times k}$ with rank $r \ll \min(d, k)$ (typically $r = 8 \dots 32$):

<Math tex="h = W_0 x + \frac{\alpha}{r} B A x" display />

- **Initialization:** $A \sim \mathcal{N}(0, \sigma^2)$ and **$B = 0$**, so at step 0 $\Delta W = B A = 0$ and the pretrained model starts completely intact!
- **QLoRA:** quantizes frozen $W_0$ to **4-bit NormalFloat (NF4)** with double quantization, fitting 70B fine-tuning onto a single GPU.
- **Zero Inference Latency:** after training, merge $W_{\text{merged}} = W_0 + \frac{\alpha}{r}BA$ directly back into the weights (or hot-swap multi-tenant adapters dynamically in **vLLM** / **SGLang**!).

y_unmerged = x @ W0.T + scale * ((x @ A.T) @ B.T)

  libraryCode={`import torch
import torch.nn as nn

class LoRALinear(nn.Module):
    def __init__(self, in_f, out_f, r=8, alpha=16):
        super().__init__()
        self.base = nn.Linear(in_f, out_f, bias=False)
        self.base.weight.requires_grad_(False)
        self.A = nn.Parameter(torch.randn(r, in_f) * 0.02)
        self.B = nn.Parameter(torch.zeros(out_f, r))
        self.scale = alpha / r

    def forward(self, x):
        return self.base(x) + self.scale * (x @ self.A.t() @ self.B.t())

layer = LoRALinear(64, 64, r=4)
trainable = sum(p.numel() for p in layer.parameters() if p.requires_grad)
total = sum(p.numel() for p in layer.parameters())
print(f"Trainable params: {trainable} / {total} ({trainable/total:.1%})")`}
