## Intuition: LLMs Inside Controlled Feedback Loops

A single prompt pass cannot check live inventory, run SQL queries, or execute unit tests. An **AI Agent** wraps an LLM in a bounded loop: the model inspects tool JSON schemas, emits structured tool arguments, receives real execution observations back in context, and iterates until solved (or max steps reached).

Rather than writing custom integration glue for every framework ($M$ models $\times$ $N$ tools), the **<GlossaryTerm term="Model Context Protocol">Model Context Protocol (MCP)</GlossaryTerm>** standardizes tool, resource, and prompt discovery over JSON-RPC between agent clients and modular MCP servers.

<Viz type="rag" />

<Callout type="warning" title="Agent Security: Least Privilege & Human-in-the-Loop">
  External documents and web pages read by tools can contain **indirect prompt injections** trying to hijack tool calls! Always enforce per-agent tool allowlists, strict schema validation, step caps (`max_steps`), and mandatory human confirmation before destructive writes (payments, DB deletes, external emails).
</Callout>

<Callout type="math-deep-dive" title="Reliability Math for Multi-Step Loops">
  If each independent tool step succeeds with probability $p = 0.95$, a 10-step fragile trajectory without validation or retries succeeds only $0.95^{10} \approx 59.9\%$ of the time! Deterministic tool schemas, self-correction observations, and narrow sub-agent scopes keep reliability high.
</Callout>

ALLOWED_TOOLS = {
    "calculate_compound": lambda principal, rate, years: round(principal * ((1 + rate) ** years), 2),
    "lookup_status": lambda service: {"service": service, "status": "healthy", "p99_ms": 42},
}

def execute_tool_call(call_json, allowlist=("calculate_compound",)):
    call = json.loads(call_json)
    name = call.get("tool")
    args = call.get("arguments", {})
    if name not in allowlist or name not in ALLOWED_TOOLS:
        return {"error": f"Tool '{name}' is blocked by agent allowlist."}
    try:
        return {"ok": True, "result": ALLOWED_TOOLS[name](**args)}
    except TypeError as exc:
        return {"error": f"Invalid arguments: {exc}"}

print(execute_tool_call('{"tool": "calculate_compound", "arguments": {"principal": 1000, "rate": 0.05, "years": 3}}'))
print(execute_tool_call('{"tool": "lookup_status", "arguments": {"service": "db"}}'))`}
