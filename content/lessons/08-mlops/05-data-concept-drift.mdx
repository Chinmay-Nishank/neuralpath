## Intuition: Models Age Even When Code Never Changes

Unlike classic backend APIs, a deployed ML model can degrade silently while returning `HTTP 200 OK`! Why? The world shifts beneath it:
- **<GlossaryTerm term="Data Drift">Data Drift (Covariate Shift)</GlossaryTerm>:** input feature distribution $P(X)$ shifts (e.g., inflation raises average transaction amounts, or mobile cameras upgrade resolution).
- **Concept Drift:** the relationship $P(Y \mid X)$ itself shifts (e.g., fraudsters invent new scams, or consumer demand shifts post-holiday).

Because ground-truth labels $Y$ often arrive days or weeks late, **PSI** and **KS tests** monitor $P(X)$ continuously as an early warning radar!

<Viz type="probability" />

<Callout type="math-deep-dive" title="Population Stability Index (PSI)">
  Bin baseline training proportions $b_i$ and live serving proportions $c_i$ across $B$ quantile buckets:

  <Math tex="\text{PSI} = \sum_{i=1}^{B} (c_i - b_i)\,\ln\!\left(\frac{c_i}{b_i}\right)" display />

  Rule-of-thumb thresholds: $\text{PSI} < 0.10$ (stable), $0.10 \le \text{PSI} < 0.25$ (moderate shift—investigate), $\text{PSI} \ge 0.25$ (significant shift—trigger evaluation/retraining).
</Callout>

  code={`import numpy as np

def compute_psi(expected_counts, actual_counts, eps=1e-6):
    e = np.asarray(expected_counts, dtype=float)
    a = np.asarray(actual_counts, dtype=float)
    p = np.maximum(e / e.sum(), eps)
    q = np.maximum(a / a.sum(), eps)
    return float(np.sum((q - p) * np.log(q / p)))

train_bins = [250, 250, 250, 250]
stable_live = [245, 255, 240, 260]
drifted_live = [80, 140, 310, 470]

print("PSI (stable traffic) :", round(compute_psi(train_bins, stable_live), 4))
print("PSI (drifted traffic):", round(compute_psi(train_bins, drifted_live), 4))`}
