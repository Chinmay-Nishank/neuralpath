## Intuition: 32 Bits Are Overkill for Trained Weights

During training, small gradient steps require FP32/BF16 precision so tiny updates don't round away to zero. Once trained, however, neural weights and activations rarely need 16–32 bits of dynamic range!

Dropping weights from FP16 (16-bit) to **INT8** (8-bit) or **AWQ/NF4** (4-bit) slashes VRAM and memory-bandwidth latency by **2× to 4×**! And when 4-bit compression still isn't small enough, **Knowledge Distillation** trains a compact student model to mimic the soft probability distribution (dark knowledge!) of a much larger teacher.

  <Math tex="W_{\text{int8}} = \text{clamp}\!\left(\text{round}(W / s),\, -127,\, 127\right), \qquad \hat{W} = s \cdot W_{\text{int8}}" display />
  **AWQ (Activation-Aware Weight Quantization)** protects the ~1% salient weight channels aligned with large activation magnitudes by scaling them up before 4-bit rounding—preserving perplexity virtually unchanged!

def quantize_int8_per_row(W):
    max_abs = np.maximum(np.max(np.abs(W), axis=-1, keepdims=True), 1e-8)
    scale = max_abs / 127.0
    q = np.clip(np.round(W / scale), -127, 127).astype(np.int8)
    return q, scale

def dequantize_int8(q, scale):
    return q.astype(np.float32) * scale

rng = np.random.default_rng(7)
W = rng.normal(0, 0.25, size=(4, 64)).astype(np.float32)
q, scale = quantize_int8_per_row(W)
W_hat = dequantize_int8(q, scale)

print("Original bytes:", W.nbytes, "-> Quantized INT8 bytes:", q.nbytes)
print("Mean absolute reconstruction error:", round(float(np.mean(np.abs(W - W_hat))), 5))`}
