## Intuition: "It Worked on My Laptop Tuesday" Breaks ML Teams

In traditional software, code + compiler determines the binary. In Machine Learning, the resulting artifact depends on **four moving axes**:
1. Code version (`git rev-parse HEAD`)
2. Exact training data snapshot (SHA-256 manifest or DVC/LakeFS hash)
3. Hyperparameters & prompt templates (`config.yaml`)
4. Random seeds & hardware determinism (`PYTHONHASHSEED`, `np.random.default_rng`, `torch.manual_seed`)

Tracking every run structurally (via MLflow, Weights & Biases, or immutable JSON manifests) ensures you can reproduce, audit, or roll back any model artifact in minutes.

<Viz type="roc-pr" />

<Callout type="tip" title="Snapshot Feature Schemas Alongside Model Weights">
  Never save a bare `model.pkl` without the exact feature column names, ordering, scaler stats, and preprocessing pipeline inside the same bundle—otherwise column reordering in production fails silently.
</Callout>

<Callout type="math-deep-dive" title="Content-Addressable Data Hashing">
  Hashing raw CSV/Parquet bytes via SHA-256 guarantees cryptographic immutability: changing a single byte in one training row changes the dataset digest completely, linking every trained checkpoint unambiguously to its exact training distribution.
</Callout>

def dataset_digest(path):
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(8192), b""):
            h.update(chunk)
    return h.hexdigest()[:16]

# Reproducible seed check
r1 = np.random.default_rng(42).normal(size=4)
r2 = np.random.default_rng(42).normal(size=4)
assert np.allclose(r1, r2)

manifest = {
    "dataset_sha": dataset_digest("/datasets/housing_mini.csv"),
    "seed": 42,
    "model": "Ridge(alpha=1.0)",
    "cv_r2": 0.912,
}
print("Immutable experiment manifest:", json.dumps(manifest, indent=2))`}
