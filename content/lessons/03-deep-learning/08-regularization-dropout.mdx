## Intuition: Forcing Redundant Representations

Deep networks easily memorize small datasets—even random labels! **Dropout** randomly zeros out hidden activations with probability $p$ on each forward step, preventing neurons from co-adapting on brittle shortcuts and acting like an exponential ensemble of sub-networks.

At inference (`model.eval()`), all neurons stay active. With **inverted dropout**, we scale active training units by $\frac{1}{1-p}$ so inference needs zero adjustment!

<Viz type="bias-variance" />

<Callout type="warning" title="Remember model.train() vs. model.eval()">
  Forgetting `model.eval()` during validation leaves Dropout enabled, injecting random noise into predictions and depressing test accuracy artificially.
</Callout>

<Callout type="math-deep-dive" title="Inverted Dropout & Label Smoothing">
  With Bernoulli mask $m \sim \text{Bernoulli}(1 - p)$:
  <Math tex="\tilde{h} = \frac{m \odot h}{1 - p} \implies \mathbb{E}[\tilde{h}] = h" display />
  For classification, **label smoothing** softens one-hot targets from $[0, 1]$ to $[\frac{\epsilon}{K}, 1 - \epsilon + \frac{\epsilon}{K}]$, preventing logits from diverging toward $\pm\infty$ and improving calibration.
</Callout>

def inverted_dropout(h, p=0.2, training=True, seed=0):
    if not training or p == 0.0:
        return h
    rng = np.random.default_rng(seed)
    mask = (rng.random(h.shape) >= p).astype(float)
    return (h * mask) / (1.0 - p)

h = np.ones((1000, 16))
dropped = inverted_dropout(h, p=0.25, training=True)
print("Target mean=1.0, Dropout sample mean:", round(float(dropped.mean()), 4))

# Simple early stopping tracker
val_losses = [0.85, 0.62, 0.49, 0.44, 0.46, 0.48, 0.52]
best_loss, patience_used, patience = float("inf"), 0, 2
for epoch, vl in enumerate(val_losses):
    if vl < best_loss:
        best_loss, patience_used = vl, 0
    else:
        patience_used += 1
    if patience_used >= patience:
        print(f"Early stopping triggered at epoch {epoch} (best val_loss={best_loss})")
        break`}
