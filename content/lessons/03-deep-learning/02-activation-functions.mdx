## Intuition: Gatekeepers of Gradient Flow

Every <GlossaryTerm term="Activation Function">activation function</GlossaryTerm> controls two things: the **shape** of hidden features during the forward pass, and the **slope** $f'(z)$ multiplied into gradients during backpropagation.

When Sigmoid saturates near $0$ or $1$, $f'(z) \approx 0$ kills gradients across deep layers. **ReLU** fixed this with constant slope $1$ for positive inputs, while modern Transformers smooth the kink around zero using **GELU** and gated **SwiGLU** blocks.

<Callout type="math-deep-dive" title="SwiGLU in Modern Transformers">
  Instead of $\text{ReLU}(x W_1) W_2$, modern LLMs (Llama 3/4, Qwen, Mistral) use **SwiGLU**, which multiplies a Swish/SiLU gate with a linear value projection:

  <Math tex="\text{SwiGLU}(x) = \big(\text{SiLU}(x W_{\text{gate}}) \odot (x W_{\text{up}})\big) W_{\text{down}}" display />

  Here $\text{SiLU}(z) = z \cdot \sigma(z)$ provides smooth gradients even for slightly negative inputs.
</Callout>

x = np.array([-3.0, -1.0, 0.0, 1.0, 3.0])

relu = np.maximum(0.0, x)
silu = x / (1.0 + np.exp(-x))
gelu = 0.5 * x * (1.0 + np.tanh(np.sqrt(2.0 / np.pi) * (x + 0.044715 * x**3)))

print("x   :", x)
print("ReLU:", np.round(relu, 3))

  libraryCode={`import torch
import torch.nn as nn
import torch.nn.functional as F

class SwiGLU(nn.Module):
    def __init__(self, d_model=16, d_ff=32):
        super().__init__()
        self.w_gate = nn.Linear(d_model, d_ff, bias=False)
        self.w_up = nn.Linear(d_model, d_ff, bias=False)
        self.w_down = nn.Linear(d_ff, d_model, bias=False)

    def forward(self, x):
        return self.w_down(F.silu(self.w_gate(x)) * self.w_up(x))

layer = SwiGLU(16, 32)
out = layer(torch.randn(2, 5, 16))
print("SwiGLU output shape:", tuple(out.shape))`}
