## Intuition: Keeping Signal Alive Across 50 Layers

If you initialize all weights to `0`, every neuron in a hidden layer receives the exact same gradient and stays permanently identical (**symmetry collapse**). If you initialize weights with standard normal `N(0, 1)`, multiplying $d_{\text{in}} = 512$ terms blows up variance by $512\times$ per layer—instantly overflowing to `NaN`!

Variance-preserving initialization scales initial standard deviation inversely with $\sqrt{n_{\text{in}}}$ so signal variance remains $\approx 1$ from input to output.

<Viz type="neural-network" />

<Callout type="math-deep-dive" title="Xavier (Glorot) vs. Kaiming (He) Variance">
  For layer $y = W x$ with independent inputs of variance $\sigma_x^2$:
  $\text{Var}(y_i) = n_{\text{in}}\,\text{Var}(W_{ij})\,\sigma_x^2$.
  - **Xavier/Glorot (Tanh/Sigmoid/Linear):** $\text{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}}$.
  - **Kaiming/He (ReLU):** ReLU zeros out half the distribution, halving variance—so we double it back:
  <Math tex="\text{Var}(W) = \frac{2}{n_{\text{in}}} \implies \sigma_W = \sqrt{\frac{2}{n_{\text{in}}}}" display />
</Callout>

<CodeRunner
  title="Testing Naive N(0, 1) vs. Kaiming Initialization Across 20 Layers"
  code={`import numpy as np

rng = np.random.default_rng(0)

def run_depth_test(init_mode):
    x = rng.normal(size=(64, 128))
    for _ in range(20):
        fan_in = x.shape[1]
        scale = 1.0 if init_mode == "naive" else np.sqrt(2.0 / fan_in)
        W = rng.normal(0.0, scale, size=(fan_in, 128))
        x = np.maximum(0.0, x @ W)
    return float(np.std(x))

print("Naive N(0,1) std after 20 ReLU layers :", run_depth_test("naive"))
print("Kaiming He   std after 20 ReLU layers :", round(run_depth_test("kaiming"), 4))`}
