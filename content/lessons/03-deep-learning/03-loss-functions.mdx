## Intuition: Your Model Optimizes Exactly What You Measure

If you train a model with MSE on noisy housing data containing a 100x typo, squared error pulls the entire model toward the outlier. **Huber loss** behaves quadratically near zero (smooth gradients) and linearly far out (robust to outliers). Meanwhile, multi-modal systems like CLIP train with **InfoNCE** to pull matching `(image, text)` pairs together and push mismatched pairs apart.

<Viz type="roc-pr" />

<Callout type="math-deep-dive" title="Numerically Stable Log-Softmax & InfoNCE">
  Evaluating $\log(\text{softmax}(z)_c)$ directly can underflow `exp(-1000) == 0`. Subtracting $m = \max_j z_j$ yields the exact **log-sum-exp** identity:

  <Math tex="-\log p_c = -z_c + m + \log \sum_j e^{z_j - m}" display />

  **InfoNCE** applies this exact multi-class cross-entropy across similarity scores $s_{ij} = \text{cos}(u_i, v_j) / \tau$ inside a batch where the diagonal $(i, i)$ is the positive target!
</Callout>

def cross_entropy_logits(logits, targets):
    m = np.max(logits, axis=-1, keepdims=True)
    log_probs = (logits - m) - np.log(np.sum(np.exp(logits - m), axis=-1, keepdims=True))
    n = len(targets)
    return float(-np.mean(log_probs[np.arange(n), targets]))

logits = np.array([[2.5, 0.3, -1.2], [0.1, 1.9, 0.2]])
targets = np.array([0, 1])
print("Stable Cross-Entropy Loss:", round(cross_entropy_logits(logits, targets), 4))

# Toy InfoNCE on batch of 3 matching pairs
emb_a = np.eye(3)
emb_b = np.array([[0.9, 0.1, 0.0], [0.1, 0.85, 0.05], [0.0, 0.2, 0.9]])
sim_logits = (emb_a @ emb_b.T) / 0.1
print("Contrastive InfoNCE Loss:", round(cross_entropy_logits(sim_logits, np.arange(3)), 4))`}

  exerciseSolution={`import numpy as np

def huber_loss(y_true, y_pred, delta=1.0):
    err = np.abs(np.asarray(y_true, dtype=float) - np.asarray(y_pred, dtype=float))
    quad = 0.5 * err ** 2
    lin = delta * (err - 0.5 * delta)
    return float(np.mean(np.where(err <= delta, quad, lin)))`}
