## Intuition: Bending Space One Hidden Layer at a Time

A single perceptron computes $y = \sigma(w^T x + b)$—just a single straight hyperplane. As Minsky and Papert highlighted in 1969, no straight line can ever separate **XOR** (`(0,0), (1,1) -> 0` vs `(0,1), (1,0) -> 1`).

Stacking a **hidden layer** of neurons with non-linear activations folds the input plane so XOR becomes linearly separable in the hidden representation!

<Callout type="math-deep-dive" title="Universal Approximation Theorem">
  Cybenko (1989) and Hornik (1991) proved that a single sufficiently wide hidden layer with non-polynomial <GlossaryTerm term="Activation Function">activations</GlossaryTerm> can approximate any continuous function on a compact domain arbitrarily closely. Deep networks achieve this **exponentially more efficiently** than shallow wide layers by composing hierarchical features.
</Callout>

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)

rng = np.random.default_rng(42)
W1 = rng.normal(0, 1.0, (2, 4))
b1 = np.zeros((1, 4))
W2 = rng.normal(0, 1.0, (4, 1))
b2 = np.zeros((1, 1))

sigmoid = lambda z: 1.0 / (1.0 + np.exp(-np.clip(z, -20, 20)))

for _ in range(2500):
    h = np.tanh(X @ W1 + b1)
    pred = sigmoid(h @ W2 + b2)
    d_out = (pred - y) / len(X)
    dW2 = h.T @ d_out
    db2 = np.sum(d_out, axis=0, keepdims=True)
    dh = (d_out @ W2.T) * (1.0 - h ** 2)
    dW1 = X.T @ dh
    db1 = np.sum(dh, axis=0, keepdims=True)
    W2 -= 0.5 * dW2; b2 -= 0.5 * db2
    W1 -= 0.5 * dW1; b1 -= 0.5 * db1

print("XOR predictions:", np.round(pred.ravel(), 3))`}

import torch.nn as nn

class ResidualMLP(nn.Module):
    def __init__(self, d_in=16, d_hid=64, d_out=2):
        super().__init__()
        self.in_proj = nn.Linear(d_in, d_hid)
        self.block = nn.Sequential(nn.LayerNorm(d_hid), nn.GELU(), nn.Linear(d_hid, d_hid))
        self.head = nn.Linear(d_hid, d_out)

    def forward(self, x):
        h = self.in_proj(x)
        return self.head(h + self.block(h))

net = ResidualMLP()
