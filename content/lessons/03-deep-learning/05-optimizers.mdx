## Intuition: Why AdamW Replaced Plain Adam

In standard L2 regularization, adding $\lambda \theta$ directly to the gradient feeds weight decay *into* Adam's adaptive denominator $\sqrt{\hat{v}_t}$. Parameters with large historical gradients get shrunk far less than intended!

**<GlossaryTerm term="AdamW">AdamW</GlossaryTerm>** (Loshchilov & Hutter, 2019) decouples weight decay cleanly: apply the adaptive gradient step first, then shrink weights directly by $\eta \lambda \theta$—giving consistent regularization across every layer.

<Callout type="math-deep-dive" title="Decoupled AdamW Update">
  <Math tex="\theta_t = \theta_{t-1} - \eta \left(\frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} + \lambda \theta_{t-1}\right)" display />
  Notice $\lambda \theta_{t-1}$ sits **outside** the $1 / \sqrt{\hat{v}_t}$ scaling factor.
</Callout>

# Minimize f(theta) = 0.5 * (theta[0]-3)^2 + 5.0 * (theta[1]+2)^2 with AdamW
theta = np.array([0.0, 0.0], dtype=float)
m = np.zeros_like(theta)
v = np.zeros_like(theta)
lr, b1, b2, eps, wd = 0.15, 0.9, 0.999, 1e-8, 0.01

for t in range(1, 81):
    g = np.array([theta[0] - 3.0, 10.0 * (theta[1] + 2.0)])
    m = b1 * m + (1 - b1) * g
    v = b2 * v + (1 - b2) * (g ** 2)
    m_hat = m / (1 - b1 ** t)
    v_hat = v / (1 - b2 ** t)
    theta = theta * (1.0 - lr * wd) - lr * m_hat / (np.sqrt(v_hat) + eps)

print("AdamW converged theta:", np.round(theta, 3))`}

  exerciseSolution={`import math

def cosine_warmup_lr(step, total_steps, warmup_steps, max_lr, min_lr=0.0):
    if step < warmup_steps:
        return max_lr * (step / max(1, warmup_steps))
    progress = min(1.0, (step - warmup_steps) / max(1, total_steps - warmup_steps))
    cosine = 0.5 * (1.0 + math.cos(math.pi * progress))
    return min_lr + (max_lr - min_lr) * cosine`}
