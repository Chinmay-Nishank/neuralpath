## Intuition: Keeping Activations Centered & Predictable

As training updates early layers, downstream layers constantly receive shifting activation distributions. Normalization layers recenter and rescale activations on the fly so optimizers stay well-conditioned:

- **BatchNorm (CNNs):** normalizes each feature channel *across the mini-batch*. Breaks down for tiny batch sizes (`batch=1`) or variable-length sequences.
- **<GlossaryTerm term="Layer Normalization">LayerNorm</GlossaryTerm> (Transformers):** normalizes *each token independently* across its $d_{\text{model}}$ features—invariant to batch size and sequence length.
- **RMSNorm (Llama, Qwen, Gemma):** drops mean subtraction entirely and divides solely by Root Mean Square magnitude, saving ~10–15% normalization compute with equal stability.

<Viz type="activations" />

<Callout type="math-deep-dive" title="LayerNorm vs. RMSNorm Equations">
  Given token hidden vector $x \in \mathbb{R}^d$ and learnable scale $\gamma$:
  <Math tex="\text{LayerNorm}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta, \qquad \text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2 + \epsilon}} \odot \gamma" display />
  Modern architectures apply normalization **before** attention and FFN blocks (**Pre-Norm**), keeping the residual highway completely clean.
</Callout>

def layer_norm(x, eps=1e-5):
    mean = np.mean(x, axis=-1, keepdims=True)
    var = np.var(x, axis=-1, keepdims=True)
    return (x - mean) / np.sqrt(var + eps)

def rms_norm(x, eps=1e-5):
    rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + eps)
    return x / rms

X = np.array([[10.0, 20.0, 30.0, 40.0], [-2.0, 0.0, 2.0, 4.0]])
